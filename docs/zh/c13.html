21设备模式与顾客显示屏

每台 BrewDesk 设备都有一项用途。门店的第一台设备会自动成为主收银台（Main POS）；从第二台设备起，您需要从下面的用途中选择一种。具体如下：

  1. Main POS（主收银台）——您的主收银台，每家门店只有一台。若要在已有主收银台的门店中更换，请使用 Replace Main POS（更换主POS），该操作需要邮件验证码。
  2. Sub POS（副收银机）——协助分担收银的设备（Register as new device）。使用店主的邮箱登录并输入验证码。（Business 套餐；含主收银台最多 3 台收银机。）
  3. Staff Ordering（员工点单）——员工可在您网络内的任何平板或手机上点单，订单会直接传送到主收银台。（Pro 套餐；会显示已使用多少个“slots”（点单位）。）
  4. Customer Display（顾客显示屏）——向顾客展示其订单的第二块屏幕。（Pro 为 1 台，Business 最多 3 台。）
  5. Waitlist Kiosk（候位名单自助机）——供到店客人自行加入候位名单的自助登记屏幕。（原名“Check-in”。）
  6. Order Kiosk（点单自助机）——即将推出。
在哪里开启

Staff Ordering 和 Customer Display 需先在主收银台上的 Settings › Add-ons（Devices 区域）中开启——Staff Ordering 是一项 Pro 附加功能。然后按以下方式注册新设备：

  1. 在新设备上打开 BrewDesk 应用，并将其连接到与主收银台相同的门店 Wi-Fi。
  2. 在登录界面，点击 “Register as a new device at Main POS.”
  3. 主收银台上会弹出 New device pairing request（新设备配对请求）窗口。在 Device role（设备用途）下选择 Staff Ordering、Customer Display 或 Waitlist Kiosk，然后点击 Approve（批准）。
  4. 新设备会直接进入您所选择的用途。
由主收银台决定设备用途，而不是新设备。新设备无法自行声明“我是员工点单平板”。完整步骤以及出现问题时的处理方法，请参见将设备添加到主收银台。
使用店主邮箱登录的设备会显示选择界面。“How will you use this device?”（您将如何使用此设备？）列出 Replace Main POS、Register as new device、Staff Ordering、Customer Display、Waitlist Kiosk 和 Order Kiosk（即将推出）。Replace Main POS 和 Register as new device 需通过邮件验证码完成（门店的第一台设备会自动成为主收银台）；Staff Ordering、Customer Display 和 Waitlist Kiosk 卡片则进入上面所述的同一个主收银台批准流程。

员工点单

员工点单让您的团队可以通过额外的平板或手机点单，订单会直接传送到主收银台。设置方法如下。

  1. 在主收银台上，于 Settings › Add-ons（Devices 区域）中开启 Staff Ordering。这是一项 Pro 附加功能。
  2. 在额外的平板或手机上打开 BrewDesk 应用，并连接到与主收银台相同的门店 Wi-Fi。
  3. 在登录界面，点击 “Register as a new device at Main POS.”
  4. 在主收银台的弹出窗口中，于 Device role 下选择 Staff Ordering，然后点击 Approve。（Pro 最多允许 3 台员工点单设备，Business 不限数量；注册界面会显示“slots used”（已用点单位）。）
  5. 员工登录后即可开始点单。
  6. 每笔订单都会自动传送到主收银台。（这台设备没有付款界面，也没有店主设置——仅用于点单。）
适合繁忙时段：员工可以直接在桌边点单，或沿着长长的队伍走动点单，让客人无需等待。
订单始终经由主收银台。员工点单平板通过门店 Wi-Fi 把每笔订单交给主收银台——因此只要主收银台已开机且处于同一网络，即使断网也能继续工作。
如果无法连接到主收银台，您会看到 Not sent to the kitchen（未发送到厨房）——“Could not reach the Main POS. This order has not reached the kitchen yet.”（无法连接主POS，此订单尚未送达厨房。）有两个按钮：Try again（重试）会再发送一次（同一笔订单绝不会重复提交），或者在您放弃并自己在主收银台上录入该订单时点击 Entered on Main POS（已在主POS录入）。只有确实已录入时才点第二个按钮——否则 BrewDesk 稍后会再次发送该订单，导致订单重复。

顾客显示屏

顾客显示屏是朝向顾客的第二块屏幕。随着您添加商品，它会向顾客显示他们的订单和价格。设置方法如下。

在哪里开启

在主收银台上的 Settings › Add-ons › Customer Display 中开启，然后在注册备用设备时选择 Customer Display 作为设备用途。

  1. 找一台闲置的平板或屏幕，在上面打开 BrewDesk，并连接到与主收银台相同的门店 Wi-Fi。
  2. 在登录界面，点击 “Register as a new device at Main POS.”
  3. 在主收银台的弹出窗口中，于 Device role 下选择 Customer Display，然后点击 Approve。
  4. 屏幕会自动与您的收银机连接，无需登录。
  5. 现在把屏幕朝向顾客。您在收银机上添加商品时，这块屏幕上也会同步显示。
  6. Pro 套餐可使用 1 块显示屏，Business 套餐最多可使用 3 块。
温馨提示：顾客显示屏只用于显示，不能点单，也不能发送任何内容——它只是向顾客展示订单。
