8折扣与促销

折扣就是从一笔销售中减去一部分金额。您可以一次性设置好欢乐时光和各种优惠，之后 BrewDesk 会在收银台为您自动计算。

  1. 在左侧边栏打开 Manage（管理）› Discounts（折扣），点击 Add Discount（添加折扣），会打开 “Create Discount” 表单。
  2. 输入 Discount Name（折扣名称）。
  3. 选择 Discount Type（折扣类型）：“Percentage”（百分比，如 9 折即减 10%）或 “Fixed Amount”（固定金额，如减 2 美元），并输入 Value（值）。
  4. 设置 Schedule（时间安排）：开始和结束日期、“All Day”（全天）或某个时间段、永不结束时选 “No End Date”，以及 Repetition（重复：不重复 / 每周 / 每月 / 自定义）。
  5. 在 Applicable Scope（适用范围）下选择适用对象：“All”（全部）商品，或用复选框勾选特定分类或商品。
  1. 选择触发方式：Automatic（自动应用：结账时自动扣减）或 Manual（手动应用：员工在结账时点击 “Apply Discount” 并选择该折扣）。
  2. 可选：设置 Minimum Order Value（最低订单金额），并开启 Allow Stacking（允许叠加），让它能与其他折扣同时使用。
  3. 点击 Save（保存）。您的折扣就设置好了。
须知：BrewDesk 始终在折扣之后计算税费，因此合计金额永远是准确的。

快捷折扣或赠送商品

预先设置的折扣适用于每周都会发生的情况。而这里针对的是一次性的情况：想照顾一下的熟客、重做的一杯饮品、请朋友的一杯咖啡。您直接在购物车里操作，大约点三下就能完成。

在哪里找到

在购物车中：点击某个商品，然后点击该行上的 Discount（折扣）或 Free（赠送）。对整张订单操作，请点击底部 Bill 旁边的 Disc 按钮。

  1. 对单个商品点击 Discount，或对整张订单点击 Disc，会打开一个键盘面板。
  2. 选择输入方式：Amount（金额，减去多少钱）或 % Percent（百分比）。
  3. 用键盘输入数字。
  4. 点击一个原因标签：Friend（朋友）、Apology（致歉）、Staff（员工）、Tasting（试吃）、Mistake（失误），或点击 "+ New" 自己填写原因。您自己添加的原因下次还会保留。
  5. 点击 Done（完成），购物车合计会立即更新。
  6. 要取消折扣，点击同一个按钮，此时它显示为 Remove Discount（取消折扣）（或 Remove Free，取消赠送）。
输入了全额？BrewDesk 会询问 "Full amount entered — record as Free instead?"（已输入全额，是否记为赠送？），并提供 Record as Free（记为赠送）。请选择“是”，这样报表就能区分“赠送”和“打折”，而这正是您在月底真正想知道的信息。
在 Settings 中创建了折扣并标记为 “Manual”？当您调整整张订单时，它会作为一个方块出现在此面板中，员工只需点击它，无需手动输入。如果您还没有创建过任何折扣，面板中有一个 Create discount（创建折扣）按钮，可直接带您前往对应界面。
打折之后又改了数量？该调整会被清除，您会看到 "Adjustment cleared — quantity changed"（数量已更改，调整已取消）。这是有意为之：两杯减 2,000 不等于五杯减 2,000，BrewDesk 宁可再问您一次，也不会悄悄猜测。

赠送商品会在日结汇总中单独成行显示，详见报表与日结。
