20设备与网络

在门店安装 BrewDesk 之前需要准备的一切——设备、打印机、刷卡读卡器和网络——都汇总在这里。它按安装顺序整理了分散在设备模式、设备配对、离线和打印机各章中的提示。具体的安装步骤，请参照安装检查清单。

设备

您可以使用已有的平板和电脑。但是，设备之间的连接（注册员工点单、顾客显示屏和候位名单自助机设备）只能在已安装的 BrewDesk 应用中进行。

设备用法 · 说明
iPad安装 BrewDesk 应用。它可以承担任何用途：主收银台、副收银机、员工点单、顾客显示屏或候位名单自助机。可直接从应用打印到 Wi-Fi/LAN 打印机或 AirPrint 打印机（小票与打印机）。
安卓平板暂不支持（安卓应用正在准备中）。目前请使用 iPad 或桌面应用。
电脑（Mac · Windows）推荐使用 BrewDesk 桌面应用。USB 打印机需通过桌面应用的 Select installed printer 连接，因此使用 USB 打印机的收银机需要安装桌面应用（小票与打印机）。
网页浏览器您可以在 brewdesk.io 注册、设置，甚至运行收银机。但浏览器画面无法注册为新设备（“Add devices from the BrewDesk app”，即请使用 BrewDesk 应用添加设备），而且在浏览器中进行 Wi-Fi 打印时，该电脑上需要运行 BrewDesk 桌面应用（brewdesk.io/downloads）（画面上可能显示为 Print Bridge）。请在所有常驻门店的设备上安装应用。
可以连接多少台设备？取决于套餐——收银机（含主收银台）：Starter 和 Pro 为 1 台，Business 为 3 台。顾客显示屏：Pro 1 台，Business 3 台。员工点单设备：Pro 3 台，Business 不限。额外的收银机（副收银机）是 Business 功能（设备模式与顾客显示屏、设备数量上限）。
请把主收银台设为全天开机的设备。员工点单平板的订单以及二维码 / 在线订单，全部经由主收银台传送。一旦它关机，二维码 / 在线点单就会暂停，系统也不会自动切换到其他设备。要连接其他设备，主收银台同样必须运行 BrewDesk 应用（多台设备与可靠性）。

小票与厨房打印机

  1. 类型——任何标准的热敏小票打印机均可。默认设置适用于 80mm 纸张（每行 42 个字符）。
  2. Wi-Fi / LAN 打印机——使用打印机的 IP 地址和端口（通常为 9100）连接。如果不知道 IP，点击 Search（搜索）。请让打印机与收银机处于同一个路由器下。
  3. USB 打印机——按常规方式在电脑上安装打印机驱动（Mac 通常自动完成，Windows 使用厂商提供的驱动），然后在桌面应用的列表中选择它。
  4. 角色——为每台打印机指定角色：Main Receipt（主收据，顾客小票）或 Kitchen（厨房，厨房单）。一台打印机可以兼任两种角色，没有厨房打印机也完全可以正常销售。
  5. 钱箱——钱箱通过小票打印机弹开，且必须在打印机设置中开启其钱箱选项。副收银机（Sub POS）无法弹开钱箱（钱箱）。
用测试打印检查。使用 Test Print（测试打印）确认纸张确实出来了，文字没有被截断或乱码。有些 Wi-Fi 打印机无法回报是否已打印（No print confirmation，无打印确认），因此请用肉眼确认（小票与打印机）。

刷卡读卡器

  1. 已连接的读卡器（Connected card readers）——BrewDesk 使用 Stripe Terminal 读卡器。款项直接进入店主自己的 Stripe 账户。读卡器需从 Stripe Dashboard 购买。
  2. 连接——首先在 Settings › Payments 中连接店主的 Stripe 账户。打开读卡器电源，让它与收银机处于同一网络，然后在同一界面的读卡器区域点击 Discover Readers（发现读卡器）→ Connect（连接）。
  3. 已有的独立刷卡终端——使用未连接 BrewDesk 的终端收取银行卡的门店，可使用付款界面上的银行卡品牌按钮进行记录（Record Only，仅记录）。请确认 Settings › Payments 中已开启 Card (Record Only)（银行卡（仅记录））（收款）。
已连接的刷卡支付需要联网。断网时您需要另一种收款方式，因此建议保持 Cash（现金）付款方式处于开启状态（哪些功能需要联网）。

Wi-Fi 与网络

BrewDesk 设备通过门店自己的网络与主收银台通信，即使断网也是如此。这使路由器成为安装中最重要的部分。

  1. 所有设备都连接同一个门店 Wi-Fi（同一个路由器）——主收银台、副收银机、员工点单平板、顾客显示屏、网络打印机和读卡器都应连接同一个网络。Wi-Fi 网络不同，是设备彼此找不到对方的最常见原因。
  2. 不要使用访客 Wi-Fi，也不要使用手机热点——如果门店另有访客 Wi-Fi，请让门店设备仅连接门店 Wi-Fi。连接访客 Wi-Fi 的设备会收到“This device is outside the store network”（此设备不在门店网络内）的提示。
  3. 关闭 AP 隔离——如果路由器开启了“AP isolation”或“wireless isolation”（无线隔离），即使在同一 Wi-Fi 下，设备之间也无法通信。请为门店 Wi-Fi 关闭该功能。
  4. 为打印机设置固定 IP——如果 Wi-Fi/LAN 打印机的 IP 地址发生变化，BrewDesk 仍会向旧地址打印。在打印机或路由器上设置固定 IP 可避免这种情况。
  5. 更换了路由器？——设备可能再也找不到主收银台。请从主收银台重新配对，并重新检查打印机 IP（将设备添加到主收银台、检查连接）。

做好断网准备

  1. 销售照常进行——离线时，点单、现金付款和小票打印仍可正常使用。网络恢复后，所有数据会自动上传，且绝不会重复（离线使用）。
  2. 真正需要联网的功能——已连接的刷卡支付、发送消息，以及创建或修改预订（哪些功能需要联网）。
  3. 保持路由器通电——只要门店 Wi-Fi 正常，员工点单平板和副收银机就能继续与主收银台通信，您甚至可以配对新设备（离线配对设备）。
  4. 安装当天在每台设备上登录一次——离线时，只有此前在该设备上登录过的账户才能进入（离线登录）。
