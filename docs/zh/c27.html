25正式营业

本节介绍如何从练习模式转入真实营业。您一开始处于练习模式。可以随意点击，录入模拟订单——这些都不会计入真实营收。准备好正式营业时，切换到正式营业即可。

在哪里查看

处于练习模式时，屏幕顶部会有一条横幅：“Practice mode — sales are not counted as real revenue”（练习模式——销售不计入真实营收）。点击旁边的 Go Live。

请在主收银台上操作。只能在您的主收银台上正式营业：“Only the main POS can switch the store to live. Open this on your main register.”（只有主POS才能将门店切换为正式营业。请在您的主收银台上打开此页面。）

填写检查清单

  1. 如果仍有缺失的内容，会先出现一份检查清单——包括门店名称、国家、币种、时区、业务类型、已确认的税率、税号、门店地址，以及至少一个菜单项。
  2. 点击某一行的 Set up（立即设置），即可直接跳转到该设置。全部填写完毕后，点击 Re-check。
为什么要拦截？如果在税率或时区仍为空的情况下就开始营业，您第一天的营收会记录错误——事后再更正要麻烦得多。所以我们请您事先确认一次。

选择开始方式

  1. 然后从三个选项中选择一个——Still practicing（继续练习，一切保持不变）、Reset and go live（清除练习记录，从零开始）或 Already in business（保留到目前为止录入的所有数据，并告诉我们您实际开业的日期）。
  2. 您还会看到一个确认界面，详细列出将被删除和将被保留的内容。
  3. 对于两个真实营业的选项，BrewDesk 会通过邮件向您发送一个需要输入的验证码——正式营业是不可逆的，所以我们要确认是您本人在操作。
  4. 完成。您的销售现在正式计入，顾客也可以用手机下单了。
已经收过真实款项？那么“Still practicing”会消失。如果 BrewDesk 发现您的账户中有真实订单、真实刷卡付款或已日结的日期，该卡片会被隐藏，并给出提示：“Real sales detected — 'Keep practicing' is not available. Choose Reset (B) or Keep data & go live (C).”（检测到真实销售——无法选择“继续练习”。请选择重置（B）或保留数据并正式营业（C）。）面板会显示它发现的内容——有多少订单、多少金额、是否使用了刷卡。把昨天的真实营收当作练习数据，会导致账目对不上。
您的菜单、税务、打印机、员工和 Stripe 设置都会保留。即使选择“Reset & start”，被清除的也仅限练习订单、销售和日结记录。

温馨提示：处于练习模式期间，顾客无法提交真实的二维码或在线订单。他们的屏幕会显示“This store is in practice mode”（此门店处于练习模式）。
