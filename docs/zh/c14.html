22多台设备与可靠性

您可以同时使用多台设备。即使其中一台出故障，另一台也能让您的门店继续营业。下面开始设置您的设备。

  1. 在将作为主收银台和副收银机的设备上，使用店主的邮箱登录。员工点单平板、顾客显示屏和候位名单自助机不使用店主邮箱登录——您需要在主收银台上批准它们（将设备添加到主收银台）。
  2. 为每台设备指定用途。可选择主收银台（您的第一号设备）、副收银机（辅助设备）、Staff Ordering（员工点单）、顾客显示屏（面向顾客的屏幕）或候位名单自助机。
  3. 以后需要更改设备的用途？在该设备上提出更改请求，然后在主收银台上批准（更改设备用途并检查连接）。
  4. 您需要选定一台设备作为主收银台——它是您的核心设备，不会自动交接。如果它掉线，BrewDesk 会立即提醒您，以便您重新开机，或将另一台设备设为主收银台。
  5. 要设置设备的模式（包括员工点单），请参见设备模式与顾客显示屏。
如果主收银台离线。您会立刻收到通知——收件箱中的一条提示、一封邮件，以及其他收银机上的横幅提醒。其他收银机仍可继续工作，但二维码和在线订单会暂停，直到主收银台恢复（参见二维码点单）。若要将另一台设备设为主收银台，需由您自己切换，BrewDesk 会通过邮件发送验证码供您确认——不会悄悄地自动切换。
为每台设备命名。在 Settings › Devices 中，点击设备名称（或旁边的小铅笔图标），输入类似 “Counter 1” 或 “Bar iPad” 的名称并保存。您会看到 “Device name updated.”（设备名称已更新。）该名称会显示在每台设备上，让您始终清楚哪台平板是哪台。仅通过门店网络连接的收银机无法重命名。
要把主收银台从列表中移除？如果已开启二维码或在线点单，BrewDesk 会先发出警告：“This is your Main POS. QR and online ordering are on — while no Main POS is connected, new customer orders can't be taken or printed in the kitchen.”（这是您的主POS。二维码和在线点单已开启——没有主POS连接时，无法接收新的顾客订单，也无法在厨房打印。）它只是警告——您仍可继续操作。如果可以，请先将另一台设备设为主收银台。
值得展示

您的收银机永远不会“罢工”。饮料洒在上面了？随便拿一台笔记本电脑或平板，几分钟就能恢复营业。不需要特殊机器，也永远不会被锁定。

将设备添加到主收银台

添加员工点单平板、顾客显示屏或候位名单自助机（自助登记）屏幕时，主收银台会自动找到它。无需输入代码，也无需到处找设置。即使门店没有网络，也能使用。

您需要准备

新设备必须已安装 BrewDesk 应用（iPad 或桌面版；安卓应用暂不可用），并且必须与主收银台处于同一个门店 Wi-Fi 下。在网页浏览器中打开的页面无法注册为设备——您只会看到 “Add devices from the BrewDesk app”（请使用 BrewDesk 应用添加设备）。

  1. 在新设备上打开 BrewDesk 应用。在登录界面，点击 “Register as a new device at Main POS.” 如果设备没有网络，它会自动进入此界面。
  2. 您会看到 “Looking for Main POS...”（正在查找主POS），随后请求会自动发送。新设备上无需再点击任何内容——让它停留在 “Waiting for approval at the Main POS.”（等待主POS批准）即可。
  3. 主收银台上会自动弹出名为 New device pairing request 的窗口，显示是哪台设备发出的请求，以及它的名称和地址。
  4. 在 Device role（设备用途）下，选择这台设备的用途——Staff Ordering、Customer Display 或 Waitlist Kiosk（自助登记）。选定之前，批准按钮保持不可用。
  5. 点击 Approve。如果您不认识该设备，请点击 Deny。
  6. 新设备会显示 New device registration complete（新设备注册完成），并直接进入您为它选择的用途。
由您决定设备用途，而不是新设备。新设备无法对您的收银机声明“我是员工点单平板”。只有站在主收银台前的人才能选择设备用途——所以，被人悄悄接入的平板无法自行决定自己能做什么。
这样永远不会生成主收银台。主收银台始终通过邮箱登录来设置，更改时 BrewDesk 会通过邮件发送验证码供您确认。副收银机（Sub POS）同样通过邮箱登录并确认验证码来注册。
提示“Couldn't find the Main POS”？通常是两台设备连接了不同的 Wi-Fi。请连接门店 Wi-Fi——不要使用访客 Wi-Fi，也不要使用手机热点——然后点击 Try again。如果弹窗停留时间过长，您会看到 Request expired（请求已过期）；只需从新设备重新开始即可。

在主收银台上，Settings › Devices 现在显示的是 How to add a device（如何添加设备）指南，而不是注册按钮——注册始终从新设备开始。

更改设备用途并检查连接

您可以更改已配对设备的用途，也可以检查它是否仍与主收银台保持通信。

  1. 在员工点单设备上，点击屏幕顶部的设备模式图标（“Switch device mode”，切换设备模式）。
  2. Change device role（更改设备用途）会打开。无需再次输入验证码——这台设备已经注册过了。
  3. 选择新的用途——Staff Ordering（在任意设备上点单）、Customer Display（向顾客展示订单）或 Waitlist Kiosk（候位名单自助登记）。
  4. 平板上暂时没有任何变化。它显示 “Waiting for Main POS approval”——“Ask the owner to approve this change on the Main POS screen. Nothing has changed on this device yet.”（请店主在主POS屏幕上批准此更改。此设备上尚未发生任何变化。）
  5. 前往您的主收银台。会自动弹出一张标有 “Role change — existing device” 的卡片：“This device is already registered and is asking to change its role. Approving changes what it does; its login is not affected.”（此设备已注册，现在请求更改其用途。批准后其功能会改变；其登录不受影响。）点击 Approve——如果这不在您的预期之内，则点击 Deny。随后平板就会切换。
  6. 在该窗口顶部，您会看到连接状态。Connected to the main POS（已连接到主POS）表示一切正常。No main POS connected（未连接主POS）表示尚未找到——请点击 Check again（重新检查）。
  7. 若要彻底移除这台设备，请点击底部的 Log out & unregister（退出并取消注册）。它会返回登录界面，重新登录后，您可以从头选择它的用途。
当情况看起来不对劲时——Connection log（连接日志）。点击屏幕顶部的连接日志图标，可在同一页面中看到这台设备注册在哪家门店、承担哪项用途、与主收银台已连接多久，以及有多少订单尚未上传。联系客服时，点击 Copy all（全部复制）并粘贴给客服——这是获得帮助最快的方式。
现在更改设备用途需要您的批准。拿着平板的人可以提出请求，但只有主收银台才能批准——所以，客人或路人无法悄悄把您的自助机变成点单设备。该请求会在 2 分钟后过期（“This request expires in {seconds}s — approve now or ask the device to send a new one”）；如果超时，只需在平板上重新请求。
将设备设为副收银机（Sub POS）需要确认两次。副收银机可以收款，所以主收银台会先提醒您——“This device will be able to take payments.” / “A Sub POS can ring up orders, take payment and issue refunds. Approve only a device you set up yourself.”（副POS可以录入订单、收款和退款。请仅批准您自己设置的设备。）点击 Continue（继续）确认。如果您不认识该设备，请点击 Deny。

达到设备数量上限时

您的套餐包含一定数量的收银机和顾客显示屏。达到这个数量后，BrewDesk 不会直接拒绝，而是为您提供用一台设备替换另一台设备的选项。

在哪里查看

一旦达到上限（不只是超出时），Settings › Devices 顶部就会显示一条警告栏，并统计您当前的使用情况——例如 Pro 为 POS 1/1 和 Customer display 1/1，Business 为 POS 3/3 和 Customer display 3/3。每台设备还会显示 Last seen（最后在线时间），让您看出哪台设备一直躺在抽屉里。

  1. 照常注册新的收银机。如果已达到上限，您会看到 “You've reached your plan's device limit. Replace an existing device, or upgrade your plan to add more.”（您已达到当前方案的设备数量上限。请更换现有设备，或升级方案以添加更多。）
  2. 会打开 Replace a device（更换设备）选择器，列出可以停用的设备。请选择其中一台。
  3. 完成——旧设备会被断开连接，新设备立即取而代之。
  4. 列表有一阵子没有变化？如果您选中的设备已经断开连接，您会看到 “That device was already disconnected, or this list is out of date — refreshing the list.”（该设备可能已被解除连接，或列表已过期——正在重新获取列表。）请在刷新后的列表中重新选择。
主收银台永远不会出现在该列表中。更换主收银台是一件更重大的事，因此有专门的途径：Replace Main POS（更换主POS）卡片，它会先确认，并通过邮件向您发送验证码。上述快速替换仅适用于其他设备。
我们也会给您发邮件。在网页端，当设备因达到上限而被拒绝时，BrewDesk 也会向店主发送邮件——消息中写着 “We've also emailed the store owner about this.”（我们也已就此事向店主发送了邮件。）这样，即使员工早上 7 点遇到这种情况，您也能知道，而无需他们再解释。
员工点单有单独的计数。Pro 包含 3 个员工点单位（Business 不限）。点单位用完时，注册界面会明确告诉您：“All 3 Staff Ordering slots are in use (3/3). Release a device in Settings → Devices to add another.”（3 个员工点单位均已占用（3/3）。请在“设置 → 设备”中释放一台设备后再添加。）如果您的套餐完全不包含该功能：“Staff Ordering isn't included in your current plan.”（当前方案不包含员工点单功能。）

在 iPad 或桌面应用上，提示语略为简短，并指引您前往网页上的 BrewDesk 账户更改套餐——替换操作本身完全相同。
