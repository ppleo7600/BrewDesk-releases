24Recibos e impresoras

BrewDesk puede imprimir recibos para los clientes y comandas para la cocina. Agreguemos una impresora paso a paso. Y si alguna vez una impresora se atasca, su pedido sigue a salvo.

  1. Abra Settings › Printers. Verá Connected Printers (Impresoras conectadas) y los botones Add USB Printer (Agregar impresora USB), Add Wi-Fi Printer (Agregar impresora Wi-Fi) y Add Printer (Agregar impresora).
  2. Toque Add Wi-Fi Printer (o Add USB Printer (Agregar impresora USB)). Se abre la ventana de la impresora.
  3. Escriba un Printer Name (Nombre de impresora), como "Impresora de cocina", para poder distinguir sus impresoras.
  4. Elija un Connection Type (Tipo de conexión): USB o Wi-Fi/LAN.
  5. Para Wi-Fi: escriba la IP Address (Dirección IP) de la impresora (como 192.168.1.50) y el Port (normalmente 9100), y toque Connect (Conectar). Si solo conoce parte de la IP, toque Search (Buscar) para buscarla.
  6. Para USB: en Select installed printer, toque Load printers y elija su impresora de la lista. (La app de escritorio de BrewDesk debe estar abierta, y la impresora debe estar instalada en su sistema operativo para aparecer en la lista).
  1. Elija el Printer Role (Rol de impresora): Main Receipt (recibos de clientes), Kitchen (comandas de cocina) o None (sin función).
  2. Si es una impresora de cocina, elija un Kitchen Print Mode (Modo de impresión cocina): Whole Order (una comanda por pedido) o Per Item (una comanda por producto). Indique Print Copies (Copias de impresión) si quiere más de una copia.
  3. Toque Test Print (Imprimir prueba) para imprimir una página de prueba y luego toque Add Printer (Agregar impresora) para guardarla.
¿Tienda con precios con impuesto incluido? Ahora la línea del impuesto lo dice. Si sus precios ya incluyen el impuesto, el recibo y la cuenta imprimen la línea del impuesto con "incl." después del rótulo. El importe no cambió y el total tampoco; está ahí para que nadie sume la línea del impuesto a los productos y crea que el total está mal. Siempre estuvo incluido; ahora el papel lo dice.
¿Se corta el texto o los caracteres que no son del inglés salen ilegibles? Abra "Printing looks wrong?" cerca de la parte inferior de la ventana de la impresora y toque Print test receipt (Imprimir recibo de prueba). Se imprime un ejemplo y usted solo responde dos cosas mirándolo: ① "Which block looked clean?" (elija aquel en que las líneas no pasaron a la línea siguiente) y ② cuál de las líneas [A] y [B] puede leer realmente. No hay números que buscar: solo elige lo que se ve bien.

Es bueno saberlo: las impresoras de 80 mm ahora usan de forma predeterminada 42 caracteres por línea, lo que sirve para la mayoría; si sus recibos se ven bien, no lo cambie. Si ningún bloque se ve bien, elija Enter number (Ingresar número) y escriba el número de la regla que aparece al final del recibo de prueba (20–96).

"No print confirmation" en una impresora Wi-Fi. Algunas impresoras Wi-Fi no pueden decirle a BrewDesk si realmente salió el papel. Su tarjeta muestra una nota gris: No print confirmation (Sin confirmación de impresión): "This printer can't report whether paper came out. A ticket that fails to print won't be flagged.". Al tocar Test Print (Imprimir prueba), verá "Test page sent. This printer can't confirm printing — check that paper came out.". Así que mire usted la impresora. No es una falla: simplemente su impresora no puede informar.
¿No sabe la dirección IP de su impresora? No hay problema. Toque Search (Buscar) y BrewDesk la busca en su red. Las impresoras Wi-Fi suelen usar el puerto 9100; si no está seguro, déjelo como está.
¿Usa un iPad? La impresión funciona dentro de la app, sin ayudante de navegador. Simplemente agregue su impresora Wi-Fi / LAN de la misma manera (toque Search (Buscar) para encontrarla) o use una impresora AirPrint.
¿No tiene impresora de cocina? No pasa nada. Si no tiene una configurada, BrewDesk simplemente omite las comandas de cocina. Nada se rompe.
¿Una impresora para ambas tareas? Si una sola impresora imprime tanto los recibos como las comandas de cocina (modo combinado), igualmente puede activar Per Item (Por artículo) para que cada producto tenga su propia comanda; es útil cuando una sola máquina hace todo.
Impresión diaria. Una vez guardada una impresora, los recibos se imprimen al cobrar y las comandas de cocina al enviar un pedido a la cocina. ¿Necesita otra copia? Abra el pedido y toque Reprint (Reimprimir). Si alguna vez falla una impresión, queda en espera en una lista; solo toque Retry (Reintentar). El pedido nunca se pierde.
Impresora USB: use el controlador instalado (recomendado)

Esta es la forma fácil. Instale el controlador de su impresora de la forma habitual (en Mac suele ser automático; en Windows se usa el controlador del fabricante), abra la app de escritorio de BrewDesk y luego, en Settings › Printers › "Add USB Printer", elija Select installed printer › Load printers y selecciónela. Las impresoras Wi-Fi / LAN tampoco necesitan este proceso.

Números de pedido y de turno

En el servicio de mostrador, cada pedido recibe un número. Es ideal para anunciar "¡ahora atendemos el número A-005!" y que los clientes sepan cuándo está lista su bebida. Así se configura y se muestra en el recibo.

  1. Abra Settings › Tables y busque las opciones de Counter Mode (Modo mostrador).
  2. Active Auto Order Number (Número de pedido automático) para que cada pedido tenga su propio número.
  3. Defina un Number Prefix (Prefijo de número) si quiere; por ejemplo, A-001.
  4. Active Daily Reset (Reinicio diario) para reiniciar la numeración cada día y empezar de cero cada mañana.
  5. El número se imprime en el recibo como número de pedido; por ejemplo, "ORDER: #TX-ORD-1042".
¿Para qué sirve el número de pedido? Es la forma fácil de entregar una bebida terminada al cliente correcto: se llama al número en lugar del nombre.

También puede diseñar el aspecto de sus recibos en Settings › Receipts. Hay pestañas para Receipt (Recibo), Kitchen (Cocina), Queue Number (Número de turno) y Waitlist Ticket (Ticket de Espera). Arrastre bloques para mostrar u ocultar cosas como un Queue Number (Número de turno) grande, un mensaje personalizado, una política de reembolsos, un sello de fidelización o un código QR. La vista previa de la derecha muestra exactamente cómo se imprimirá.

¿Quiere el número bien grande? Active el bloque Queue Number (Número de turno) en el diseñador de recibos. La vista previa de la derecha se actualiza a medida que cambia las cosas, así que siempre ve cómo quedará el recibo impreso.
