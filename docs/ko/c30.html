7카드 결제 준비 · Stripe 연결

카드 · QR · 온라인 주문 결제를 받으려면 매장 이름으로 된 Stripe 계정을 BrewDesk 에 한 번 연결합니다. 입력은 보통 15분이고, Stripe 검토가 걸리면 영업일 1~2일 걸립니다. 결제 대금은 BrewDesk 를 거치지 않고 매장 Stripe 계정으로 바로 들어갑니다.

한눈에 4단계

① 서류 챙기기 → ② POS Settings › Payments 맨 아래 Payment providers(결제사 연동)에서 Stripe 누르기 → ③ Connect Stripe 누르고 Stripe 화면에 사장님이 직접 입력 → ④ 돌아와서 Connected(연결됨) 확인

Stripe 계정은 사장님 것입니다. 설치를 도와준 판매자(총판)가 있어도 사장님 본인 정보 · 매장 계좌로 만듭니다. 대표(Owner) 로그인으로 메인 POS 에서 합니다. 사장님 앱(휴대폰)에서는 연결할 수 없습니다.

① 시작 전에 챙길 것 (싱가포르 기준)

먼저 매장 나라 · 이름 확인 — 나라는 연결 뒤에 못 바꿉니다

Settings › Store Info 에서 Country(나라) · 주소 · Store Name(매장 이름)이 실제와 같은지 봅니다. Stripe 계정의 나라는 처음 연결할 때 이 값으로 고정됩니다.

준비물메모
☐ UEN (사업자 등록번호)Stripe 가 UEN 으로 ACRA 기록을 불러와 대조합니다. 사업자 이름 · 주소 · 사업 형태를 ACRA BizFile 과 똑같이 넣습니다.
☐ 대표자 본인 · SingpassACRA 에 Owner · Director 로 올라 있는 사람이 직접 입력합니다. Singpass 로 본인 확인하면 가장 빠릅니다. Singpass 를 못 쓰면 NRIC · FIN · 여권 중 하나(컬러, 원본 사진)와 셀카. 싱가포르 밖에 사는 대표자는 여권만 됩니다.
☐ 정산 은행 계좌매장(사업자) 명의의 싱가포르 은행 계좌.
☐ 법인이면 소유자 · 이사지분 25% 이상 소유자와 이사. Stripe 가 ACRA 에서 미리 채워 주니 맞는지만 확인합니다.
☐ 사장님 이메일 · 휴대폰매일 보는 이메일(정산 · 서류 요청 메일이 옵니다), 인증 코드를 받을 휴대폰 실물.
☐ 매장 설명 · 카드 명세서 이름웹사이트나 SNS 주소(없으면 매장 설명), 손님 카드 명세서에 찍힐 매장 이름.

근거(Stripe 공식): 싱가포르 확인 요건 · 법인(Private company) · 인정 서류 · 2026-10 확인

대표자가 아닌 사람이 입력하면 Stripe 가 CEO · Director 가 서명한 위임장(Letter of Authority, 12개월 이내)을 따로 요구합니다. 사장님이 직접 하시는 것이 가장 빠릅니다.

②③ 연결하기

  1. 메인 POS 에서 Settings › Payments 를 열고 맨 아래 Payment providers 의 Stripe 줄을 누릅니다.
  1. Connect Stripe 를 누릅니다. Stripe 가입 페이지가 열립니다.
  1. Email address 가 사장님 이메일인지 보고 Continue. 휴대폰 · 이메일로 온 인증 코드를 넣습니다.
  2. Stripe 가 묻는 순서대로 입력합니다 — UEN · 사업 정보 → 대표자 본인 확인(Singpass) → 법인이면 소유자 · 이사 확인 → 정산 계좌.
  3. 마지막 화면에서 제출하면 BrewDesk 의 Payments 화면으로 자동으로 돌아옵니다.

④ 끝났는지 확인

  • Stripe 줄이 Connected(연결됨)이면 끝입니다. 매장 이메일로 Stripe connected 메일이 한 번 갑니다. 이 창의 Charges 는 「결제 받기」 상태라는 뜻입니다(수수료가 아닙니다).
  • 계속 Not connected 이면 아직 끝나지 않았거나 Stripe 검토 중입니다. 아래 막힐 때를 보세요.
  • 연결되면 결제수단의 Stripe card 와 받는 곳 표의 Needs connection(연결 필요) 칸이 풀립니다. 매장 카드 단말기로 받는 Counter terminal · record only(기록용 카드)도 그대로 함께 쓸 수 있습니다.

막힐 때

이럴 때이렇게 하세요
중간에 창을 닫았다 · Stripe 화면이 만료됐다Payments › Stripe › Connect Stripe 를 다시 누릅니다. Stripe 화면이 다시 열리면 남은 칸을 채웁니다.
제출했는데 계속 Not connectedStripe 검토 중입니다. 보통 몇 분, 길면 영업일 1~2일. 사장님 메일함에 Stripe 메일이 왔는지 봅니다. 아무 메일이 없으면 Connect Stripe 를 한 번 더 눌러 남은 칸이 있는지 확인합니다.
Stripe 가 서류를 더 달라고 한다Stripe 대시보드 Settings › Business › Account status 에 필요한 것이 나옵니다. 서류는 그 화면에서만 올립니다(메일로 보내지 않습니다).
신분증 · 서류가 거절됐다흔한 이유: 화면 캡처(안 됨 — 원본 사진이나 PDF), 흑백 사진, 모서리가 잘림, 뒷면 빠짐, 만료, 이름이 입력값과 다름. 고쳐서 다시 올립니다.
사업자 이름 · 이사가 맞지 않는다고 한다ACRA BizFile 과 철자 · 띄어쓰기까지 똑같이 고칩니다. 이사 · 소유자 목록이 다르면 12개월 이내 서류로 증명하라고 합니다.
대표자가 아니라서 위임장을 요구한다Director 가 서명한 Letter of Authority 를 올리거나, ACRA 에 오른 대표자가 직접 다시 진행합니다.
은행 계좌가 확인되지 않는다사업자 명의 계좌인지, 계좌 번호 · 은행이 맞는지 봅니다. 개인 계좌는 거절될 수 있습니다.

거절 사유 근거: Stripe 인정 서류 · 거절 이유

나라별로 되는지

구분나라안내
Stripe + 카드 리더싱가포르 · 호주 · 뉴질랜드 · 일본 · 말레이시아 · 미국 · 캐나다 (퀘벡 주는 BrewDesk 미판매)이 장대로 연결합니다.
Stripe 만 (카드 리더 불가)태국 · 아랍에미리트QR · 온라인 주문 카드 결제만 됩니다.
Stripe 미리보기 (영업 문의 필요)인도네시아일반 가입은 사실상 안 됩니다. 아래 「안 되는 나라」처럼 씁니다.
Stripe 불가베트남 · 아르헨티나 · 남아프리카공화국Stripe 연결을 하지 않습니다.

2026-10 기준 · Stripe 사정에 따라 바뀔 수 있음. 출처: stripe.com/global · docs.stripe.com/terminal/payments/regional

안 되는 나라의 매장은 매장 카드 단말기로 카드를 받고, POS 에서는 Counter terminal · record only(기록용 카드)로 남깁니다.

수수료는 누가 받나요

  • Stripe 결제 수수료는 Stripe 가 매장 Stripe 계정에서 직접 받습니다. 싱가포르 국내 카드 기준 3.4% + S$0.50 입니다(해외 카드는 추가 요금이 있습니다). 정확한 요율은 Stripe 대시보드에서 확인합니다.
  • BrewDesk 수수료는 매장에서 받는 결제는 0%, 온라인 주문만 0.4% 입니다.
  • 온라인 주문의 수수료를 메뉴 가격으로 메우고 싶으면 QR 주문의 Online price increase(온라인 가격 인상)를 쓰세요.

연결한 다음

  • 카드 리더를 쓰려면 카드 단말을 따라 리더를 연결합니다.
  • 어디서 어떤 결제를 받을지는 같은 Payments 화면의 결제수단 · 받는 곳 표에서 정합니다. 결제 받는 방법은 결제 받기를 보세요.

연결 해제는 시험 삼아 하지 마세요

Stripe 창 아래의 Disconnect(연결 해제)를 누르고 확인하면 Stripe 연결 계정이 삭제되어 Stripe 카드 · QR 결제가 바로 멈춥니다(현금 · 기록용 카드는 그대로 됩니다). 사장님 앱으로 결제 실패 알림이 갑니다. 나라가 틀려 다시 연결해야 하는 경우에만, 영업 중이 아닐 때 하십시오.
