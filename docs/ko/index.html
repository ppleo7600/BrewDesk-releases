사용 설명서 & 기능 안내

카페, 식당, 바, 미용실에 필요한 모든 것 — 그리고 있으면 정말 좋은 몇 가지 기능까지.

★ 5분이면 바로 시작 ★ 플랫폼 카드 수수료 없음 ★ 오프라인에서도 작동 ★ POS는 절대 멈추지 않습니다

빠른 길잡이 역할별 시작하기

지금 맡은 일에 맞는 순서대로 읽어 주세요. 링크를 누르면 해당 장으로 바로 이동합니다.

1. 처음 출근한 직원

오늘부터 계산대를 맡는다면 이 순서로 익히면 됩니다.

  1. 직원 빠른 시작 (한 페이지)
  2. 주문 받기
  3. 결제 받기
  4. 계산대에서 바로 깎기 (즉석 할인)
  5. 환불
  6. 인터넷이 끊겼을 때

2. 사장님

가게를 열고 운영하기까지의 순서입니다.

  1. 빠른 시작
  2. 매장 설정
  3. 메뉴 만들기
  4. 애드온
  5. 플랜 & 결제
  6. 사장님 앱 — 사용법은 사장님 앱 상단의 매뉴얼 버튼에서 볼 수 있습니다
  7. 직원 & 권한
  8. 마감 · 리포트

3. 설치 기사

매장에 기기를 설치하고 넘겨 드릴 때의 순서입니다.

  1. 설치 준비물 & 네트워크
  2. 메인 POS · 기기 모드
  3. 기기 연결
  4. 프린터
  5. 오프라인 · Wi-Fi
  6. 라이브 전환
  7. 설치 체크리스트
  8. 문제 해결

처음 보는 말이 있나요? 용어집에서 메인 POS · Z-Report · 자리 비움 잠금 같은 용어를 한 줄로 확인할 수 있습니다. 자주 받는 질문은 자주 묻는 질문에 짧게 정리했습니다.

여기서 시작 사장님들이 BrewDesk를 좋아하는 이유

중요한 것부터 — BrewDesk를 특별하게 만드는 점들입니다. 이 안내서 곳곳에 있는 ★ 금색 표시를 찾아보시기 바랍니다. 자랑할 만한 기능을 알려 줍니다.

★ 5분이면 설정 끝

가입하고, 업종을 선택하고, AI가 시작 메뉴를 만들어 주면 바로 첫 주문을 받을 수 있습니다 — 설치도, 교육도, 신용카드도 필요 없습니다.

★ 플랫폼 카드 수수료 없음 — 언제나

BrewDesk는 카드 매출에서 단 한 푼도 떼지 않습니다. 매출이 더 많이 남습니다.*

★ 오프라인에서도, 언제나 영업

인터넷이 끊겨도 계속 판매할 수 있습니다. 주문은 기기에 저장되고, 인터넷이 돌아오면 바로 동기화됩니다.

★ POS는 절대 멈추지 않습니다

어떤 노트북이나 태블릿도 몇 분이면 계산대가 됩니다. 기기가 고장 나도 가게는 멈추지 않습니다.

★ Stripe 계정 연동 — 무료

본인 Stripe 계정을 연결해 카드를 받아 주세요. 연동은 모든 플랜에서 무료이며, BrewDesk는 Stripe 수수료 위에 아무것도 더하지 않습니다.

★ 하나의 앱, 여러 업종

카페, 식당, 바, 베이커리, 미용실, 스파 — BrewDesk가 실제 업무 방식에 맞게 스스로 모습을 바꿉니다.

* 결제 대행사의 기본 수수료는 사장님이 직접 그쪽에 지불합니다 — BrewDesk는 그 위에 아무것도 더하지 않습니다.
