사용 설명서 & 기능 안내

카페, 식당, 바, 미용실에 필요한 모든 것 — 그리고 있으면 정말 좋은 몇 가지 기능까지.

★ 5분이면 바로 시작 ★ 플랫폼 카드 수수료 0% ★ 오프라인에서도 작동 ★ POS는 절대 멈추지 않아요

여기서 시작 사장님들이 BrewDesk를 좋아하는 이유

중요한 것부터 — BrewDesk를 특별하게 만드는 점들이에요. 이 안내서 곳곳에 있는 ★ 금색 표시를 찾아보세요. 자랑할 만한 기능을 알려줘요.

★ 5분이면 설정 끝

가입하고, 업종을 고르고, AI가 시작 메뉴를 만들어 주면 바로 첫 주문을 받아요 — 설치도, 교육도, 신용카드도 필요 없어요.

★ 플랫폼 카드 수수료 0% — 언제나

BrewDesk는 카드 매출에서 단 한 푼도 떼지 않아요. 매출이 더 많이 남아요.*

★ 오프라인에서도, 언제나 영업

인터넷이 끊겨도 계속 팔 수 있어요. 주문은 기기에 저장되고, 인터넷이 돌아오면 바로 동기화돼요.

★ POS는 절대 멈추지 않아요

어떤 노트북이나 태블릿도 몇 분이면 계산대가 돼요. 기기가 고장 나도 가게는 멈추지 않아요.

★ Stripe 계정 연동 — 무료

본인 Stripe 계정을 연결해 카드를 받으세요. 연동은 모든 플랜에서 무료이고, BrewDesk는 Stripe 수수료 위에 0%만 더해요.

★ 하나의 앱, 여러 업종

카페, 식당, 바, 베이커리, 미용실, 스파 — BrewDesk가 실제 일하는 방식에 맞게 스스로 모습을 바꿔요.

* 결제 대행사의 기본 수수료는 사장님이 직접 그쪽에 내요 — BrewDesk는 그 위에 0%만 더해요.
