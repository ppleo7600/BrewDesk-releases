2빠른 시작 — 5분이면 바로 시작

첫 판매를 가장 빨리 하는 방법이에요. 약 5분이면 돼요. 작은 단계를 하나씩 따라 해보세요.

  1. 웹 브라우저를 열고 brewdesk.io로 가요.
  2. 이메일과 비밀번호를 입력해 가입해요. 신용카드는 필요 없어요.
  3. 어떤 가게인지 골라요. 카페, 식당, 바, 미용실, 스파, 베이커리 중에서 고르면 BrewDesk가 거기에 맞게 설정해요.
  4. AI 메뉴 만들기 버튼을 탭해요. 몇 초 만에 시작 메뉴가 만들어져요. (직접 몇 가지 입력해도 돼요.)
  5. 주문 화면을 찾아요. 상품을 탭해 주문에 담아요.
  6. Cash를 탭하면 바로 판매가 끝나요. "판매 완료" 메시지가 떠요. 끝이에요 — 첫 판매 완료!
  7. 나중에 카드를 받고 싶으면 본인 Stripe 계정을 연결하면 돼요. (방법은 7장에서 알려드려요.)
잘못해도 걱정 마세요. 나중에 Settings에서 무엇이든 바꿀 수 있어요. 여기서 정한 건 영구적인 게 아니에요.
이걸 자랑하세요

5분, 설치할 것 없음, 교육 필요 없음. 다른 계산대는 설정 통화를 예약하게 만들어요. BrewDesk는 커피가 식기 전에 판매를 시작하게 해줘요.

처음 설정 (7단계)

처음 가입하면 친절한 마법사가 몇 가지 간단한 단계를 안내해요. 무엇을 묻는지 순서대로 알려드려요. 그냥 따라서 탭하면 돼요.

  1. 업종(Business Type) — 어떤 가게인지 골라요: 카페, 식당, 바, 미용실, 스파, 베이커리.
  2. 매장 정보(Store Info) — 매장 이름을 입력하고, 나라나 지역을 고르고, 계산대(till)가 몇 대인지 알려줘요.
  3. 서비스 모드(Service Mode) — Counter(카운터에서 주문) 또는 Table 서비스(테이블에서 주문)를 골라요.
  4. 애드온(Add-ons) — 원하는 추가 기능을 켜요. 나중에 바꿀 수 있으니 걱정 마세요.
  5. 플랜(Plan) — Starter(무료), Pro, Business 중에서 골라요. Pro와 Business는 1개월 무료 체험이 있고, 시작할 때 신용카드가 필요 없어요.
  6. 메뉴(Menu) — 준비된 템플릿으로 시작하거나, AI가 만들게 하거나, 직접 추가해요. (AI 메뉴 만들기는 4장에서 더 알려드려요.)
  7. 사장님 PIN(Owner PIN) — 화면을 잠글 PIN을 정해요. 이 단계는 선택이에요.

끝이에요! 간단한 세금 안내만 확인하면 바로 팔 준비가 돼요.

전체가 약 5분이면 돼요. 그리고 기억하세요 — 무엇이든 나중에 Settings에서 바꿀 수 있어요.

연습 모드에서 진짜 영업으로 (라이브 전환)

처음엔 연습 모드로 시작해요. 마음껏 눌러보고 가짜 주문을 넣어봐도 실제 매출로 잡히지 않아요. 진짜로 장사를 시작할 준비가 되면 라이브로 바꿔요.

누르는 곳

연습 모드일 때 화면 맨 위에 "Practice mode — sales are not counted as real revenue"(연습 모드 · 실제 매출로 집계되지 않습니다) 띠가 보여요. 그 옆의 "Go Live"(라이브 전환)를 탭해요.

  1. 빠진 설정이 있으면 먼저 확인 목록이 떠요 — 매장 이름, 국가, 통화, 시간대, 업종, 세율 확인, 사업자 등록번호, 매장 주소, 메뉴 1개 이상.
  2. 각 줄의 "Set up"(설정하기)을 누르면 그 설정 화면으로 바로 가요. 다 채우고 "Re-check"(다시 확인)를 누르세요.
  3. 다 되면 셋 중에 골라요 — "Still practicing"(연습 더 하기 · 아무것도 바뀌지 않아요), "Reset and go live"(연습 기록 지우고 깨끗하게 시작), "Already in business"(지금까지 기록을 그대로 두고 라이브 · 실제로 문을 연 날짜를 함께 지정해요).
  4. 고른 내용을 한 번 더 확인하는 화면이 나와요. 무엇이 지워지고 무엇이 남는지 목록으로 보여줘요.
  5. 진짜로 넘어가는 두 가지(B·C)는 이메일로 인증 코드를 보내드려요. 라이브 전환은 되돌릴 수 없는 문이라 한 번 더 본인 확인을 해요.
  6. 완료! 이제 매출이 공식 기록으로 쌓이고, 손님도 휴대폰으로 주문할 수 있어요.
이미 진짜 돈을 받았다면 "연습 더 하기"는 사라져요. 실제 주문·카드 결제·마감 기록이 하나라도 있으면 그 카드가 감춰지고 이렇게 알려줘요 — "Real sales detected — 'Keep practicing' is not available. Choose Reset (B) or Keep data & go live (C)."(실제 매출이 확인돼 '연습 유지'는 고를 수 없어요. 초기화(B)나 데이터 유지(C) 중에서 고르세요.) 옆 패널에 무엇이 발견됐는지(주문 수·금액·카드 사용 여부·마감 건수)도 보여줘요. 어제 받은 진짜 돈을 연습이었다고 해 버리면 장부가 그때부터 안 맞아요.
메인 계산대에서 하세요. 라이브 전환은 메인 POS에서만 돼요 — "Only the main POS can switch the store to live. Open this on your main register."(메인 POS에서만 라이브로 바꿀 수 있어요. 메인 계산대에서 열어 주세요.)
왜 미리 막나요? 세율이나 시간대가 비어 있는 채로 진짜 영업을 시작하면 첫날 매출이 어긋난 채로 기록돼요. 나중에 고치기가 훨씬 번거로워서, 시작 전에 한 번만 확인받는 거예요.
메뉴·세금·프린터·직원·Stripe 설정은 그대로 남아요. "초기화하고 라이브"를 골라도 지워지는 건 연습 중 쌓인 주문·매출·마감 기록뿐이에요.

알아두기: 연습 모드에서는 손님이 QR·온라인으로 실제 주문을 넣을 수 없어요. 손님 화면에는 "이 매장은 연습 모드입니다"라고 보여요.
