2빠른 시작

첫 판매를 가장 빨리 하는 방법입니다. 약 5분이면 충분합니다. 작은 단계를 하나씩 따라 해 주세요.

  1. 웹 브라우저를 열고 brewdesk.io로 이동합니다.
  2. 이메일과 비밀번호를 입력해 가입합니다. 신용카드는 필요하지 않습니다.
  3. 어떤 가게인지 선택합니다. 카페, 식당, 바, 미용실, 스파, 베이커리 중에서 선택하면 BrewDesk가 그에 맞게 설정합니다.
  4. AI 메뉴 만들기 버튼을 탭합니다. 몇 초 만에 시작 메뉴가 만들어집니다. (직접 몇 가지를 입력해도 됩니다.)
  5. 주문 화면을 찾습니다. 상품을 탭해 주문에 담습니다.
  6. Cash를 탭하면 바로 판매가 끝납니다. "판매 완료" 메시지가 표시되며, 이것으로 첫 판매가 완료됩니다.
  7. 나중에 카드 결제를 받으려면 본인의 Stripe 계정을 연결하면 됩니다. (방법은 결제 받기에서 안내합니다.)
잘못 설정해도 걱정하지 않으셔도 됩니다. 나중에 Settings에서 무엇이든 바꿀 수 있습니다. 여기서 정한 내용은 영구적인 것이 아닙니다.
자랑할 만한 점

5분, 설치할 것 없음, 교육 필요 없음. 다른 계산대는 설정 통화를 예약하게 합니다. BrewDesk는 커피가 식기 전에 판매를 시작할 수 있게 해 줍니다.

처음 설정 (7단계)

처음 가입하면 설정 마법사가 몇 가지 간단한 단계를 안내합니다. 무엇을 묻는지 순서대로 설명합니다. 안내에 따라 탭하면 됩니다. 왼쪽 위에서 Quick(빠른) 모드를 고르면 서비스 모드·애드온 단계는 건너뛰고, Full(전체) 모드는 아래 7단계를 모두 거칩니다.

  1. 업종(Business Type) — 어떤 가게인지 선택합니다: 카페, 식당, 바, 미용실, 스파, 베이커리.
  2. 매장 정보(Store Info) — 매장 이름을 입력하고, 나라나 지역을 선택하고, 계산대(till)가 몇 대인지 입력합니다.
  3. 서비스 모드(Service Mode) — Counter(카운터에서 주문) 또는 Table 서비스(테이블에서 주문)를 선택합니다.
  4. 애드온(Add-ons) — 원하는 추가 기능을 켭니다. 나중에 바꿀 수 있으므로 걱정하지 않으셔도 됩니다.
  5. 플랜(Plan) — Starter(무료), Pro, Business 중에서 선택합니다. Pro와 Business는 1개월 무료 체험이 제공되며, 시작할 때 신용카드가 필요하지 않습니다.
  6. 메뉴(Menu) — 준비된 템플릿으로 시작하거나, AI가 만들게 하거나, 직접 추가합니다. (AI 메뉴 만들기는 메뉴 만들기에서 더 자세히 안내합니다.)
  7. 완료(Done) — "Setup complete!" 화면에서 설정 내용을 확인합니다. 카드 결제를 받으려면 여기서 Connect Stripe를 탭해 연결하고, 나중에 Settings › Payments에서 연결해도 됩니다. 마지막으로 Start using BrewDesk를 탭합니다.

Staff 애드온을 고른 경우에만 메뉴 단계 다음에 사장님 PIN(Owner PIN) 단계가 하나 더 나타납니다(4자리 PIN, 건너뛸 수 있습니다). 이 단계가 나오면 전체 단계가 8개가 됩니다.

이것으로 설정이 끝납니다. 간단한 세금 안내만 확인하면 바로 판매할 준비가 됩니다.

전체가 약 5분이면 끝납니다. 무엇이든 나중에 Settings에서 바꿀 수 있다는 점을 기억해 주세요.

준비가 끝나면 라이브 전환에서 연습 모드를 실제 영업으로 바꿉니다.
