21기기 모드 & 고객 디스플레이

BrewDesk 기기는 저마다 한 가지 용도를 맡습니다. 매장의 첫 기기는 자동으로 메인 계산대(Main POS)가 되고, 그다음 기기부터는 아래 용도 중에서 고릅니다. 용도는 다음과 같습니다.

  1. Main POS — 메인 계산대. 주 계산대이며 매장에 한 대뿐입니다. 이미 있는 매장에서 바꾸려면 Replace Main POS(메인 POS 교체)를 사용하며, 이메일 인증 코드가 필요합니다.
  2. Sub POS — 도와주는 추가 계산대(Register as new device). 사장님 이메일로 로그인하고 인증 코드를 입력해 등록합니다. (Business 플랜; 메인 계산대를 포함해 최대 3대.)
  3. Staff Ordering — 직원이 매장 네트워크의 어떤 태블릿이나 휴대폰에서든 주문을 받고, 주문이 바로 메인 계산대로 전달됩니다. (Pro 플랜; 사용 중인 "slots used"를 표시합니다.)
  4. Customer Display — 손님에게 주문을 보여 주는 두 번째 화면. (Pro 플랜 1대, Business 플랜 최대 3대.)
  5. Waitlist Kiosk — 워크인 손님이 직접 대기열에 이름을 올리는 셀프 체크인 화면. (이전에 "Check-in"이라고 부르던 화면입니다.)
  6. Order Kiosk — 곧 출시.
켜는 곳

Staff Ordering과 Customer Display는 먼저 메인 계산대의 Settings › Add-ons(Devices 섹션)에서 켭니다 — Staff Ordering은 Pro 애드온입니다. 그런 다음 새 기기에서 아래 순서로 등록합니다.

  1. 새 기기에서 BrewDesk 앱을 열고, 메인 계산대와 같은 매장 Wi-Fi에 연결합니다.
  2. 로그인 화면 아래의 "메인포스에 새기기로 등록"(Register as a new device at Main POS)을 탭합니다.
  3. 메인 계산대에 "새 기기 페어링 요청" 팝업이 나타납니다. "기기 용도"에서 Staff Ordering · Customer Display · Waitlist Kiosk 중 하나를 고르고 "승인"을 탭합니다.
  4. 새 기기가 사장님이 고른 용도의 화면으로 자동으로 들어갑니다.
용도는 새 기기가 아니라 메인 계산대에서 정합니다. 새 기기가 스스로 "나는 직원 주문용입니다"라고 정할 수 없습니다. 자세한 단계와 문제 해결 방법은 새 기기를 메인 계산대에 붙이기를 참고해 주세요.
사장님 이메일로 로그인한 기기에서는 용도 선택 화면이 나옵니다. "이 기기를 어떻게 쓰시겠어요?"(How will you use this device?) 화면에 Replace Main POS · Register as new device · Staff Ordering · Customer Display · Waitlist Kiosk · Order Kiosk(곧 출시) 카드가 표시됩니다. Replace Main POS와 Register as new device는 이메일 인증 코드를 거치며(매장의 첫 기기라면 자동으로 메인 계산대가 됩니다), Staff Ordering · Customer Display · Waitlist Kiosk 카드는 위와 같은 메인 계산대 승인 흐름으로 이어집니다.

Staff Ordering

Staff Ordering은 직원이 추가 태블릿이나 휴대폰에서 주문을 받을 수 있게 합니다. 주문은 바로 메인 계산대로 전달됩니다. 설정하는 방법은 다음과 같습니다.

  1. 메인 계산대의 Settings › Add-ons(Devices 섹션)에서 Staff Ordering을 켭니다. Pro 애드온입니다.
  2. 추가 태블릿이나 휴대폰에서 BrewDesk 앱을 열고, 메인 계산대와 같은 매장 Wi-Fi에 연결합니다.
  3. 로그인 화면 아래의 "메인포스에 새기기로 등록"을 탭합니다.
  4. 메인 계산대 팝업의 "기기 용도"에서 Staff Ordering을 선택하고 "승인"합니다. (직원 주문 기기는 Pro 플랜 3대까지, Business 플랜은 제한이 없으며 등록 화면에 "slots used"로 표시됩니다.)
  5. 직원이 로그인해서 주문을 받기 시작합니다.
  6. 각 주문이 자동으로 메인 계산대로 전달됩니다. (이 기기에는 결제 화면도, 사장님 설정도 없습니다 — 주문만 받는 용도입니다.)
바쁠 때 유용합니다: 직원이 테이블에서 바로 주문을 받거나, 긴 줄을 따라 이동하며 아무도 기다리지 않게 할 수 있습니다.
주문은 항상 메인 계산대를 거칩니다. Staff Ordering 태블릿은 모든 주문을 매장 Wi-Fi로 메인 계산대에 전달합니다 — 따라서 인터넷이 끊겨도 메인 계산대가 켜져 있고 같은 네트워크에 있으면 그대로 작동합니다.
메인 계산대에 연결되지 않으면 "주방에 전달되지 않았습니다"(Not sent to the kitchen)라고 표시됩니다 — "메인 POS 에 연결할 수 없습니다. 이 주문은 아직 주방에 가지 않았습니다." 버튼은 두 개입니다. "다시 시도"(Try again)는 한 번 더 전송합니다(같은 주문이 두 번 들어가는 일은 없습니다). "메인 POS 에 직접 입력함"(Entered on Main POS)은 전송을 포기하고 메인 계산대에 직접 입력했을 때만 눌러 주세요 — 실제로 입력하지 않았는데 누르면 안 되며, 반대로 입력했는데 누르지 않으면 나중에 자동으로 한 번 더 전송되어 주문이 두 번 들어갑니다.

고객 디스플레이

고객 디스플레이는 손님을 향한 두 번째 화면입니다. 상품을 담는 동안 손님에게 주문과 가격을 보여 줍니다. 설정하는 방법은 다음과 같습니다.

켜는 곳

메인 계산대의 Settings › Add-ons › Customer Display에서 켠 다음, 여분 기기를 등록할 때 용도로 Customer Display를 선택해 주세요.

  1. 여분 태블릿이나 화면을 준비해 BrewDesk 앱을 열고, 메인 계산대와 같은 매장 Wi-Fi에 연결합니다.
  2. 로그인 화면 아래의 "메인포스에 새기기로 등록"을 탭합니다.
  3. 메인 계산대 팝업의 "기기 용도"에서 Customer Display를 선택하고 "승인"합니다.
  4. 화면이 자동으로 계산대와 연결됩니다. 로그인은 필요 없습니다.
  5. 이제 화면을 손님 쪽으로 돌려 놓습니다. 계산대에서 상품을 담으면 이 화면에도 표시됩니다.
  6. Pro 플랜은 디스플레이 1대, Business 플랜은 최대 3대까지 사용할 수 있습니다.
알아 두면 좋습니다: 고객 디스플레이는 보여 주기만 합니다. 주문을 받거나 무언가를 전송할 수 없습니다 — 손님에게 주문만 보여 줍니다.
