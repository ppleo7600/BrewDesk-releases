22문제 해결 & 지원

가끔 문제가 생길 수 있으며, 걱정하지 않으셔도 됩니다. 가장 흔한 문제의 빠른 해결 방법과 도움을 요청하는 방법을 안내합니다.

  1. Card 버튼이 회색이고 눌리지 않나요? 아직 Stripe 계정을 연결하지 않은 상태입니다. 7장에서 연결해 주세요.
  2. 인터넷이 끊겼나요? 걱정하지 마시고 그대로 판매를 계속해 주세요. BrewDesk는 오프라인에서도 정상 작동합니다. 15장을 참고해 주세요.
  3. 주방 티켓이 출력되지 않았나요? 프린터가 켜져 있는지 확인하고 재시도 목록을 확인해 주세요. 18장을 참고해 주세요.
  4. 흰 화면만 표시되거나 업데이트 후 앱이 멈춘 것 같나요? 화면 위쪽의 새로고침/캐시 비우기(Refresh / Clear cache) 버튼을 탭하고 확인해 주세요. 오래된 앱 파일을 삭제하고 최신 버전을 새로 불러오며, 저장된 주문과 설정은 안전하게 유지됩니다.
  5. 그래도 해결되지 않나요? 앱에서 설정 › 지원(Support) › Create New Ticket을 탭하여 지원 티켓을 엽니다(저희에게 메시지를 보낸다는 뜻입니다). 또는 brewdesk.io를 방문해 주세요.
새로고침/캐시 비우기(Refresh / Clear cache)는 업데이트 직후에 사용하기 적합한 빠른 해결 방법입니다. 저장된 주문이나 설정은 건드리지 않고 앱의 최신 버전을 새로 불러옵니다.
지원 티켓은 저희 지원팀에 보내는 메시지입니다. 어떤 문제가 있는지 알려 주시면 답변해 드리겠습니다.
버튼이 잘리거나 글씨가 너무 작나요? 오른쪽 위 계정 메뉴를 열고 화면 배율(Display Scaling)을 확인해 주세요. 자동(Auto)으로 두면 BrewDesk가 기기 크기에 맞게 자동으로 조정하며 현재 배율(%)도 표시합니다. 직접 설정하려면 수동(Manual)으로 변경하면 됩니다. 화면이 작은 태블릿에서 특히 유용합니다.
로그인하지 않은 상태이거나, 로그인하지 못하는 분을 도와 주고 계신가요? 로그인 없이 볼 수 있는 안내 페이지가 있습니다 — brewdesk.io/support. 문의 메일 주소, 답변까지 보통 소요되는 시간, 그리고 자주 묻는 질문(오프라인 동작, 하드웨어, 카드 결제, 기기 대수 한도, 해지, 데이터 보관 위치)이 정리되어 있습니다. 이 페이지는 영어로만 제공됩니다.

자동 업데이트

BrewDesk는 계속 개선되며, 계산대는 새 버전을 자동으로 받습니다. 영업 중간에 방해하는 일은 없습니다. 업데이트가 언제 이루어지고 어떤 화면이 표시되는지 안내해 드립니다.

  1. 업데이트는 그날 계산대를 켠 직후에만 시작되며, 사용 중에는 시작되지 않습니다. 화면 새로고침은 해당하지 않고, 실제로 앱을 다시 켠 경우여야 합니다.
  2. 그때에도 안전한 상태인지 먼저 확인합니다. 장바구니가 비어 있고, 결제 중이 아니며, 온라인 상태이고, 아직 전송하지 못한 자료가 없어야 합니다. 하나라도 충족되지 않으면 다음 날로 미룹니다.
  3. 시작 전에 3초 예고가 표시됩니다 — "업데이트를 시작합니다"(Starting the update) → "3초 뒤에 시작해요."
  4. 지금 진행하기 어려우면 화면을 한 번 눌러 주세요. 안내에도 "화면을 누르면 다음에 할게요"(Tap the screen to do this later)라고 표시됩니다. 한 번 누르면 업데이트가 취소되고 하던 작업을 계속할 수 있으며, 다음에 켤 때까지 다시 묻지 않습니다.
  5. 그대로 두면 업데이트 화면이 나타납니다. 로고 아래에 현재 진행 중인 작업이 한 줄로 표시됩니다 — "새 버전을 확인하고 있어요" → "화면을 불러오고 있어요" → "매장 정보를 불러오고 있어요". 업데이트는 기기마다 하루 한 번만 진행됩니다.
시간이 오래 걸리면 그 사실을 안내합니다. 15초쯤 지나면 문구가 "조금 더 걸리고 있어요. 그대로 두시면 됩니다."로 바뀝니다. 고장이 아니며, 그대로 두면 완료됩니다.
급한 경우에는 저장된 정보로 먼저 시작해 주세요. 22초쯤 지나도 끝나지 않으면 "매장 정보를 기다리는 중이에요."와 함께 "저장된 정보로 시작하기"(Start with saved data) 버튼이 나타납니다. 이 버튼을 누르면 기기에 이미 있는 정보로 매장 화면에 바로 들어가 다음 손님을 받을 수 있습니다.
화면을 계속 지켜보실 필요는 없습니다. 화면 아래에는 항상 "업데이트가 끝나면 저절로 매장 화면으로 돌아옵니다."라는 문구가 표시됩니다. 만약 업데이트가 끝까지 진행되지 못하면 계산대를 붙잡아 두지 않고 중단합니다 — "이번엔 업데이트를 건너뛰었어요. 쓰던 화면 그대로 사용하시면 됩니다."

직접 업데이트하기 — 대기가 발생하는 이유

다음 날 아침까지 기다리지 않고 직접 업데이트를 실행할 수도 있습니다. 변경된 내용의 목록이 표시되고 그 아래에 업데이트 버튼이 있습니다.

  1. 업데이트 버튼을 누릅니다. 계산대가 사용 중이면 어떤 데이터도 잃지 않은 채 대기하며, 그 이유를 한 줄로 안내합니다.
  2. "아직 주문이 열려 있어요. 정리 후에 적용할게요." — 장바구니를 결제하거나 보류해 주세요.
  3. "결제가 진행 중이에요. 끝나면 적용할게요." — 결제 도중에는 절대 개입하지 않습니다.
  4. "인터넷 연결을 확인해 주세요." 또는 "아직 전송되지 않은 주문이 있어요. 모두 전송되면 적용할게요." — 주문이 안전하게 전송될 때까지 기다립니다.
  5. 조건이 충족되면 "새 버전을 받는 중"(Getting the new version)이라고 표시되고, 완료되면 자동으로 매장 화면으로 새로고침됩니다.
시간이 오래 걸리나요? 20초쯤 지나면 "조금 더 걸리고 있어요. 그대로 두셔도 됩니다."로 바뀝니다. 새 버전을 끝내 받지 못하면 "지금은 새 버전을 받지 못했어요. 잠시 후 다시 시도해 주세요."라는 문구가 나타납니다. 고장이 아니며 손실된 데이터도 없으므로, 손님을 계속 받으시고 나중에 다시 눌러 주세요.
업데이트가 완료된 뒤에는 안내가 표시됩니다. 다음에 계산대를 켜면 짧은 안내가 나타납니다 — "이번 업데이트에는 개선 사항과 버그 수정이 포함되어 있습니다." 화면이 조금 달라 보여도 영문을 몰라 당황하실 일이 없습니다.
