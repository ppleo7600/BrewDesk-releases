22문제 해결 & 지원

가끔 일이 잘 안 풀려요 — 괜찮아요. 가장 흔한 문제의 빠른 해결법과, 도움을 청하는 방법이에요.

  1. Card 버튼이 회색이고 안 눌려요? 아직 Stripe 계정을 연결하지 않았어요. 7장에서 연결하세요.
  2. 인터넷이 끊겼어요? 걱정 마세요 — 그냥 계속 파세요. BrewDesk는 오프라인에서 잘 작동해요. 15장을 보세요.
  3. 주방 티켓이 안 나왔어요? 프린터가 켜져 있는지 확인하고 재시도 목록을 보세요. 18장을 보세요.
  4. 흰 화면만 나오거나, 업데이트 후 앱이 멈춘 것 같아요? 화면 위쪽의 새로고침/캐시 비우기(Refresh / Clear cache) 버튼을 탭하고 확인하세요. 오래된 앱 파일을 지우고 최신 버전을 새로 불러와요 — 저장된 주문과 설정은 안전해요.
  5. 그래도 막혔어요? 앱에서 Help를 탭해 지원 티켓을 열어요(우리에게 메시지를 쓴다는 뜻이에요). 또는 brewdesk.io로 가세요.
새로고침/캐시 비우기(Refresh / Clear cache)는 업데이트 직후에 딱 좋은 빠른 해결법이에요. 저장된 주문이나 설정은 건드리지 않고 앱의 최신 버전을 새로 불러와요.
지원 티켓은 우리 지원팀에 보내는 메시지일 뿐이에요. 무엇이 잘못됐는지 알려주시면 답해드릴게요.
버튼이 잘리거나 글씨가 너무 작나요? 오른쪽 위 계정 메뉴를 열고 화면 배율(Display Scaling)을 보세요. 자동(Auto)으로 두면 BrewDesk가 기기 크기에 맞춰 알아서 맞추고, 지금 몇 %인지도 보여줘요. 직접 정하고 싶으면 수동(Manual)으로 바꾸면 돼요. 화면이 작은 태블릿에서 특히 도움이 돼요.
로그인하지 않은 상태거나, 로그인 못 하는 분을 도와주고 있나요? 로그인 없이 볼 수 있는 안내 페이지가 있어요 — brewdesk.io/support. 문의 메일 주소, 보통 얼마나 걸려 답하는지, 그리고 자주 묻는 질문(오프라인 동작, 하드웨어, 카드 결제, 기기 대수 한도, 해지, 데이터 보관 위치)이 정리돼 있어요. 영어로만 되어 있어요.

BrewDesk가 스스로 업데이트할 때

BrewDesk는 계속 좋아지고, 계산대는 새 버전을 알아서 받아요. 장사 중간에 끼어드는 일은 없어요 — 언제 일어나고 무엇이 보이는지 알려드릴게요.

  1. 업데이트는 그날 계산대를 켠 직후에만 시작해요 — 쓰는 중에는 안 해요. 화면 새로고침은 해당하지 않고, 진짜로 앱을 다시 켠 경우여야 해요.
  2. 그때도 안전한지 먼저 확인해요. 장바구니가 비어 있고, 결제 중이 아니고, 온라인이고, 아직 못 올린 자료가 없어야 해요. 하나라도 아니면 다음 날로 미뤄요.
  3. 시작 전에 3초 예고가 떠요 — "업데이트를 시작합니다"(Starting the update) → "3초 뒤에 시작해요."
  4. 지금은 곤란하세요? 화면을 한 번 누르면 돼요. 안내에도 "화면을 누르면 다음에 할게요"(Tap the screen to do this later)라고 쓰여 있어요. 한 번 누르면 취소되고 하던 일을 계속해요. 다음에 켤 때까지 다시 묻지 않아요.
  5. 그대로 두면 업데이트 화면이 떠요. 로고 아래 지금 뭘 하는지 한 줄로 알려줘요 — "새 버전을 확인하고 있어요" → "화면을 불러오고 있어요" → "매장 정보를 불러오고 있어요". 기기마다 하루 한 번만 해요.
오래 걸리면 오래 걸린다고 말해줘요. 15초쯤 지나면 문구가 "조금 더 걸리고 있어요. 그대로 두시면 됩니다."로 바뀌어요. 고장이 아니에요 — 그냥 두면 끝나요.
급하면 저장된 정보로 먼저 시작하세요. 22초쯤 지나도 안 끝나면 "매장 정보를 기다리는 중이에요."와 함께 "저장된 정보로 시작하기"(Start with saved data) 버튼이 나와요. 누르면 기기에 이미 있는 정보로 매장 화면에 바로 들어가서 다음 손님을 받을 수 있어요.
지켜보고 있을 필요 없어요. 화면 아래에 항상 "업데이트가 끝나면 저절로 매장 화면으로 돌아옵니다."라고 쓰여 있어요. 혹시 업데이트가 끝까지 못 가면 붙잡아 두지 않고 포기해요 — "이번엔 업데이트를 건너뛰었어요. 쓰던 화면 그대로 사용하시면 됩니다."

직접 업데이트하기 — 가끔 기다리는 이유

다음 날 아침까지 기다리지 않고 직접 업데이트를 부를 수도 있어요. 무엇이 새로워졌는지 목록이 뜨고 그 아래에 업데이트 버튼이 있어요.

  1. 업데이트 버튼을 눌러요. 계산대가 바쁘면 아무것도 잃지 않고 대기하면서 이유를 한 줄로 알려줘요.
  2. "아직 주문이 열려 있어요. 정리 후에 적용할게요." — 장바구니를 결제하거나 보류해 주세요.
  3. "결제가 진행 중이에요. 끝나면 적용할게요." — 결제 도중에는 절대 끼어들지 않아요.
  4. "인터넷 연결을 확인해 주세요." 또는 "아직 전송되지 않은 주문이 있어요. 모두 전송되면 적용할게요." — 주문이 안전하게 올라갈 때까지 기다려요.
  5. 괜찮아지면 "새 버전을 받는 중"(Getting the new version)이라고 뜨고, 끝나면 저절로 매장 화면으로 새로고침돼요.
오래 걸리나요? 20초쯤 지나면 "조금 더 걸리고 있어요. 그대로 두셔도 됩니다."로 바뀌어요. 정말 못 받으면 "지금은 새 버전을 받지 못했어요. 잠시 후 다시 시도해 주세요."라고 해요. 고장도 아니고 잃은 것도 없어요 — 손님을 계속 받으시고 나중에 다시 누르면 돼요.
업데이트된 뒤에는 알려줘요. 다음에 계산대를 켜면 짧은 안내가 떠요 — "이번 업데이트에는 개선 사항과 버그 수정이 포함되어 있습니다." 화면이 조금 달라 보여도 영문을 몰라 당황할 일이 없어요.
