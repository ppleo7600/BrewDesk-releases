18영수증 & 프린터

BrewDesk는 손님용 영수증과 주방용 티켓을 인쇄할 수 있습니다. 프린터를 단계별로 추가하는 방법을 안내해 드립니다. 프린터에 문제가 생겨도 주문은 안전하게 보관됩니다.

  1. Settings › Printers를 엽니다. "Connected Printers"와 "Add USB Printer", "Add Wi-Fi Printer", "Add Printer" 버튼이 표시됩니다.
  2. "Add Wi-Fi Printer"(또는 "Add USB Printer")를 탭합니다. 프린터 창이 열립니다.
  3. "Printer Name"을 입력합니다. "Kitchen Printer"와 같은 이름으로 프린터를 구분합니다.
  4. "Connection Type"을 선택합니다 — USB 또는 Wi-Fi/LAN.
  5. Wi-Fi의 경우: 프린터의 "IP Address"(예: 192.168.1.50)와 "Port"(보통 9100)를 입력하고 "Connect"를 탭합니다. IP 일부만 알고 있다면 "Search"를 탭하여 찾습니다.
  6. USB의 경우: "설치된 프린터 선택"에서 "프린터 목록 불러오기"를 눌러 목록에서 프린터를 선택하면 완료됩니다. (BrewDesk 데스크탑 앱이 켜져 있어야 하며, 프린터가 OS에 설치되어 있어야 목록에 표시됩니다.)
  7. "Printer Role"을 선택합니다: "Main Receipt"(손님 영수증), "Kitchen"(주방 티켓), "None"(역할 없음).
  8. 주방 프린터라면 "Kitchen Print Mode"를 선택합니다: "Whole Order"(주문당 티켓 1장) 또는 "Per Item"(상품당 티켓 1장). 여러 장이 필요하면 "Print Copies"를 설정합니다.
  9. "Test Print"를 탭하여 테스트 페이지를 인쇄한 뒤 "Add Printer"를 탭해 저장합니다.
세금 포함 가격을 사용하는 매장이라면 세금 줄에 표시가 붙습니다. 판매가에 세금이 이미 포함된 매장은 영수증·계산서의 세금 줄 라벨 뒤에 "incl."(포함)이 표시됩니다. 금액과 합계는 변함이 없습니다 — 품목 금액에 세금 줄을 더하여 합계가 틀렸다고 오해하는 일을 막기 위한 표시입니다. 세금은 원래부터 포함되어 있었으며, 이제 종이 영수증에도 그렇게 기재됩니다.
글자가 잘리거나 한글이 깨져서 출력되나요? 프린터 창 아래쪽의 "인쇄가 이상한가요?(Printing looks wrong?)"를 펼치고 "테스트 영수증 출력"을 눌러 주세요. 영수증에 샘플이 인쇄되면 다음 두 가지만 선택하면 됩니다 — ① 어느 블록이 깔끔하게 출력되었나요?(줄이 다음 줄로 넘어가지 않은 쪽을 선택해 주세요) ② [A]와 [B] 중 한글이 제대로 읽히는 쪽. 숫자를 모르셔도 됩니다. 눈으로 확인하고 선택하기만 하면 완료됩니다.

알아두기: 80mm 프린터의 기본 글자 수는 42자입니다. 대부분 이 설정으로 정상 출력되므로 인쇄에 문제가 없다면 이 부분은 변경하지 않으셔도 됩니다. 둘 다 맞지 않으면 "직접 입력"을 선택하고 영수증 맨 아래 눈금의 숫자(20~96)를 입력해 주세요.

Wi-Fi 프린터에 「인쇄 확인 불가(No print confirmation)」가 표시되는 경우 일부 Wi-Fi 프린터는 종이가 실제로 출력되었는지 BrewDesk에 알려주지 못합니다. 해당 프린터 카드에 회색 안내가 나타납니다: "인쇄 확인 불가" — 이 프린터는 종이가 나왔는지 알려주지 못합니다. 인쇄 실패가 표시되지 않을 수 있습니다. "Test Print"를 누르면 "테스트 인쇄를 보냈습니다. 이 프린터는 인쇄 확인을 지원하지 않으니 종이가 나왔는지 확인해 주세요."라는 문구가 나타납니다. 따라서 프린터를 직접 눈으로 확인해 주세요. 고장이 아니며, 프린터가 알려주지 못할 뿐입니다.
프린터 IP 주소를 모르시나요? 괜찮습니다. "Search"를 탭하면 BrewDesk가 네트워크를 검색하여 찾아 줍니다. Wi-Fi 프린터는 보통 포트 9100을 사용하므로, 잘 모르면 기본값 그대로 두어 주세요.
iPad를 사용하시나요? iPad 앱에서는 브라우저 도우미 없이 앱 안에서 바로 인쇄됩니다. Wi-Fi / LAN 프린터를 같은 방법으로 추가하거나("Search"로 찾기) AirPrint 프린터를 사용하시면 됩니다.
주방 프린터가 없으신가요? 괜찮습니다. 설정된 프린터가 없으면 BrewDesk가 주방 티켓 출력을 건너뜁니다. 아무 문제가 없습니다.
한 대로 두 가지를 모두 처리하시나요? 한 프린터가 영수증과 주방 티켓을 모두 인쇄하는(겸용 모드) 경우에도 "Per Item"(항목별)을 켤 수 있습니다 — 그러면 상품마다 주방 티켓이 한 장씩 출력됩니다. 한 대로 전부 처리할 때 편리합니다.
평소 인쇄. 프린터를 저장하면 결제할 때 영수증이 인쇄되고, 주문을 주방에 보내면 주방 티켓이 인쇄됩니다. 한 장이 더 필요하면 주문을 열고 Reprint를 탭해 주세요. 인쇄가 실패하면 목록에서 대기하므로 Retry만 탭해 주세요. 주문은 절대 유실되지 않습니다.
USB 프린터 — 설치된 드라이버로 (권장)

가장 쉬운 방법입니다. 프린터의 드라이버를 평소처럼 설치하고(Mac은 보통 자동, Windows는 제조사 드라이버), BrewDesk 데스크탑 앱을 켠 다음, Settings › Printers › "Add USB Printer"에서 "설치된 프린터 선택" › "프린터 목록 불러오기"로 프린터를 선택하면 완료됩니다. Wi-Fi / LAN 프린터에는 이 과정이 필요하지 않습니다.

주문 & 대기 번호

카운터 서비스에서는 모든 주문에 번호가 부여됩니다. "A-005번 손님 나오십시오!"와 같이 호출하기 편리하여 손님이 음료가 언제 준비되었는지 알 수 있습니다. 번호를 설정하고 영수증에 표시하는 방법을 안내합니다.

  1. Settings › Tables를 열고 Counter Mode 옵션을 찾습니다.
  2. 모든 주문에 번호가 부여되도록 "Auto Order Number"를 켭니다.
  3. 필요하면 "Number Prefix"를 설정합니다 — 예를 들어 A-001.
  4. 매일 번호를 다시 시작하려면 "Daily Reset"을 켭니다. 아침마다 번호가 새로 시작됩니다.
  5. 번호가 주문 번호로 영수증에 인쇄됩니다 — 예를 들어 "ORDER: #TX-ORD-1042".
주문 번호는 어디에 사용하나요? 완성된 음료를 알맞은 손님과 맞추는 쉬운 방법입니다 — 이름 대신 번호를 부르면 됩니다.

영수증 모양도 Settings › Receipts에서 직접 디자인할 수 있습니다. "Receipt", "Kitchen", "Waitlist" 탭이 있습니다. 블록을 끌어다 놓아 큰 "Queue Number", 맞춤 메시지, 환불 정책, 스탬프, QR 코드 등을 표시하거나 숨길 수 있습니다. 오른쪽 실시간 미리보기에서 인쇄될 모습을 그대로 확인할 수 있습니다.

번호를 크고 보기 좋게 표시하고 싶으신가요? 영수증 빌더에서 "Queue Number" 블록을 켜 주세요. 변경할 때마다 오른쪽 미리보기가 갱신되므로 인쇄될 영수증 모습을 항상 확인할 수 있습니다.
