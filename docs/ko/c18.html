18영수증 & 프린터

BrewDesk는 손님용 영수증과 주방용 티켓을 인쇄할 수 있어요. 프린터를 단계별로 추가해봐요. 그리고 프린터가 막혀도 주문은 여전히 안전해요.

  1. Settings › Printers를 열어요. "Connected Printers"와 "Add USB Printer", "Add Wi-Fi Printer", "Add Printer" 버튼이 보여요.
  2. "Add Wi-Fi Printer"(또는 "Add USB Printer")를 탭해요. 프린터 창이 열려요.
  3. "Printer Name"을 입력해요. "Kitchen Printer" 같은 이름으로 프린터를 구분해요.
  4. "Connection Type"을 골라요 — USB 또는 Wi-Fi/LAN.
  5. Wi-Fi의 경우: 프린터의 "IP Address"(예: 192.168.1.50)와 "Port"(보통 9100)를 입력하고 "Connect"를 탭해요. IP 일부만 안다면 "Search"를 탭해 찾아요.
  6. USB의 경우: "설치된 프린터 선택"에서 "프린터 목록 불러오기"를 눌러 목록에서 프린터를 고르면 끝이에요. (BrewDesk 데스크탑 앱이 켜져 있어야 하고, 프린터는 OS에 설치돼 있어야 목록에 떠요.)
  7. "Printer Role"을 골라요: "Receipt"(손님 영수증) 또는 "Kitchen"(주방 티켓).
  8. 주방 프린터라면 "Kitchen Print Mode"를 골라요: "Whole Order"(주문당 티켓 1장) 또는 "Per Item"(상품당 티켓 1장). 여러 장이 필요하면 "Print Copies"를 정해요.
  9. "Test"를 탭해 테스트 페이지를 인쇄하고, "Save"를 탭해요.
세금 포함 가격인 매장이라면, 세금 줄에 표시가 붙어요. 판매가에 세금이 이미 들어 있는 매장은 영수증·계산서의 세금 줄 라벨 뒤에 "incl."(포함)이 붙어 나와요. 금액도, 합계도 그대로예요 — 품목 금액에 세금 줄을 더해서 합계가 틀렸다고 오해하는 일을 막으려고 붙인 표시예요. 원래부터 포함돼 있었고, 이제 종이에도 그렇게 적히는 거예요.
글자가 잘리거나 한글이 깨져 나오나요? 프린터 창 아래쪽 "인쇄가 이상한가요?(Printing looks wrong?)"를 펼치고 "테스트 영수증 출력"을 누르세요. 영수증에 샘플이 인쇄되면 두 가지만 고르면 돼요 — ① 어느 블록이 깔끔하게 나왔나요?(줄이 다음 줄로 안 넘어간 쪽을 고르세요) ② [A]와 [B] 중 한글이 제대로 읽히는 쪽. 숫자를 모르셔도 돼요. 눈으로 보고 고르기만 하면 끝이에요.

알아두기: 80mm 프린터의 기본 글자수는 42자예요. 대부분 이대로 잘 나오니, 인쇄가 멀쩡하면 이 부분은 건드리지 않으셔도 돼요. 둘 다 안 맞으면 "직접 입력"으로 영수증 맨 아래 눈금의 숫자(20~96)를 넣으세요.

Wi-Fi 프린터에 「인쇄 확인 불가(No print confirmation)」가 보여요. 어떤 Wi-Fi 프린터는 종이가 진짜 나왔는지 BrewDesk에 알려주지 못해요. 그 프린터 카드에 회색 안내가 떠요: "인쇄 확인 불가" — 이 프린터는 종이가 나왔는지 알려주지 못합니다. 인쇄 실패가 표시되지 않을 수 있습니다. "Test"를 누르면 "테스트 인쇄를 보냈습니다. 이 프린터는 인쇄 확인을 지원하지 않으니 종이가 나왔는지 확인하세요."라고 나와요. 그러니 프린터를 직접 눈으로 확인해 주세요. 고장이 아니에요 — 프린터가 알려주지 못할 뿐이에요.
프린터 IP 주소를 모르나요? 괜찮아요. "Search"를 탭하면 BrewDesk가 네트워크를 뒤져 찾아요. Wi-Fi 프린터는 보통 포트 9100을 써요 — 잘 모르면 그대로 두세요.
iPad인가요? iPad 앱에서는 브라우저 도우미 없이 앱 안에서 바로 인쇄돼요. Wi-Fi / LAN 프린터를 같은 방법으로 추가하거나("Search"로 찾기), AirPrint 프린터를 쓰면 돼요.
주방 프린터가 없나요? 괜찮아요. 설정된 게 없으면 BrewDesk가 주방 티켓을 그냥 건너뛰어요. 아무 문제 없어요.
한 대로 두 가지를 다 하나요? 한 프린터가 영수증과 주방 티켓을 모두 인쇄하는(겸용 모드) 경우에도 "Per Item"(항목별)을 켤 수 있어요 — 그러면 상품마다 주방 티켓이 한 장씩 나와요. 한 대로 전부 처리할 때 편리해요.
평소 인쇄. 프린터를 저장하면 결제할 때 영수증이 인쇄되고, 주문을 주방에 보내면 주방 티켓이 인쇄돼요. 한 장 더 필요해요? 주문을 열고 Reprint를 탭하세요. 인쇄가 실패하면 목록에서 기다려요 — Retry만 탭하세요. 주문은 절대 잃어버리지 않아요.
USB 프린터 — 설치된 드라이버로 (권장)

가장 쉬운 방법이에요. 프린터의 드라이버를 평소처럼 설치하고(Mac은 보통 자동, Windows는 제조사 드라이버), BrewDesk 데스크탑 앱을 켠 다음, Settings › Printers › "Add USB Printer"에서 "설치된 프린터 선택" › "프린터 목록 불러오기"로 프린터를 고르면 끝이에요. Wi-Fi / LAN 프린터도 이 과정이 필요 없어요.

주문 & 대기 번호

카운터 서비스에서는 모든 주문에 번호가 붙어요. "A-005번 손님 나오세요!" 하고 부르기 좋아서 손님이 음료가 언제 준비됐는지 알 수 있어요. 설정하고 영수증에 표시하는 방법이에요.

  1. Settings › Tables를 열고 Counter Mode 옵션을 찾아요.
  2. 모든 주문에 번호가 붙도록 "Auto Order Number"를 켜요.
  3. 원하면 "Number Prefix"를 정해요 — 예를 들어 A-001.
  4. 매일 번호를 다시 시작하려면 "Daily Reset"을 켜요. 아침마다 새로 시작해요.
  5. 번호가 주문 번호로 영수증에 인쇄돼요 — 예를 들어 "ORDER: #ORD-1042".
주문 번호는 뭐에 쓰나요? 완성된 음료를 알맞은 손님과 맞추는 쉬운 방법이에요 — 이름 대신 번호를 부르면 돼요.

영수증 모양도 Settings › Receipts에서 직접 디자인할 수 있어요. "Receipt", "Kitchen", "Waitlist Ticket" 탭이 있어요. 블록을 끌어다 큰 "Queue Number", 맞춤 메시지, 환불 정책, 스탬프, QR 코드 같은 걸 보이거나 숨겨요. 오른쪽 실시간 미리보기가 인쇄될 모습을 그대로 보여줘요.

번호를 크고 보기 좋게? 영수증 빌더에서 "Queue Number" 블록을 켜요. 바꾸는 대로 오른쪽 미리보기가 갱신돼서 인쇄될 영수증 모습을 늘 볼 수 있어요.
