14여러 대 기기 & 안정성

여러 대 기기를 동시에 쓸 수 있어요. 하나가 고장 나도 다른 기기가 가게를 계속 열어줘요. 기기를 설정해봐요.

  1. 각 기기에서 BrewDesk를 열고 로그인해요.
  2. 각 기기에 역할을 줘요. 메인 계산대(1번 기기), 추가 계산대(도우미 기기), 디스플레이(손님용 화면) 중에서 골라요.
  3. 나중에 기기 역할을 바꿔야 해요? 대시보드에서, 멀리서도 할 수 있어요.
  4. 한 기기를 메인 계산대로 정해요 — 이게 기준(앵커)이에요. 저절로 넘어가지 않아요. 메인 계산대가 오프라인이 되면 BrewDesk가 바로 알려줘서, 다시 켜거나 다른 기기를 메인 계산대로 만들 수 있어요.
  5. Staff Ordering을 포함해 기기 모드를 설정하려면 13장을 보세요.
메인 계산대가 오프라인이 되면. 바로 알려드려요 — 인박스 알림, 이메일, 그리고 다른 계산대의 배너로요. 다른 계산대는 계속 작동하지만, QR·온라인 주문은 메인 계산대가 돌아올 때까지 잠시 멈춰요(11장 참고). 다른 기기를 메인 계산대로 바꾸려면 사장님이 직접 전환하고, BrewDesk가 확인용 코드를 이메일로 보내요 — 아무것도 조용히 저절로 넘어가지 않아요.
기기마다 이름을 붙여 보세요. Settings › Devices에서 기기 이름(또는 옆의 작은 연필 아이콘)을 누르고, "카운터 1", "바 아이패드"처럼 적고 저장해요. "Device name updated."가 보여요. 이름은 모든 기기에 똑같이 보여서 어떤 태블릿이 어떤 건지 늘 알 수 있어요. 매장 네트워크로만 연결된 기기는 이름을 바꿀 수 없어요. (일부 문구는 영어로 표시돼요.)
메인 계산대를 목록에서 빼려는 경우. QR·온라인 주문이 켜져 있으면 먼저 경고가 떠요: 메인 POS 입니다. QR·온라인 주문이 켜져 있어, 메인 POS 가 없는 동안에는 손님 주문을 받을 수 없고 주방 인쇄도 되지 않습니다… 경고만 하고 막지는 않아서 계속 진행할 수 있어요. 가능하면 다른 기기를 먼저 메인 계산대로 정해 두세요.
이걸 자랑하세요

계산대는 절대 멈추지 않아요. 음료를 쏟았다고요? 아무 노트북이나 태블릿을 잡으면 몇 분이면 돌아와요. 특별한 기계도 없고, 묶이는 일도 없어요.

새 기기를 메인 계산대에 붙이기

직원 주문용 태블릿, 고객 디스플레이, 체크인 화면을 새로 붙일 때는 메인 계산대가 알아서 찾아줘요. 코드를 적을 필요도, 설정을 뒤질 필요도 없어요. 인터넷이 끊긴 매장에서도 돼요.

준비물

새 기기에 BrewDesk 앱이 깔려 있어야 해요(아이패드 · 안드로이드 태블릿 · 데스크탑). 그리고 메인 계산대와 같은 매장 Wi-Fi에 연결돼 있어야 해요. 인터넷 브라우저로 연 화면은 기기로 등록할 수 없어요 — 그때는 "Add devices from the BrewDesk app"(BrewDesk 앱에서 기기를 추가하세요)라고 알려줘요.

  1. 새 기기에서 BrewDesk 앱을 열어요. 로그인 화면 아래의 "메인포스에 새기기로 등록"(Register as a new device at Main POS)을 탭해요. 인터넷이 끊긴 상태면 이 화면으로 저절로 넘어가요.
  2. "메인포스 찾는 중…"(Looking for Main POS...)이 뜨고, 찾으면 요청을 자동으로 보내요. 새 기기에서는 더 누를 게 없어요 — "메인포스에서 승인을 기다리는 중입니다"(Waiting for approval at the Main POS)가 뜨면 그대로 두세요.
  3. 메인 계산대 화면에 "새 기기 페어링 요청"(New device pairing request) 팝업이 저절로 떠요. 어떤 기기가 요청했는지 이름과 주소가 보여요.
  4. 팝업의 "기기 용도"(Device role)에서 이 기기를 무엇으로 쓸지 골라요 — Staff Ordering(직원 주문) · Customer Display(고객 디스플레이) · Waitlist Kiosk(대기열 셀프 체크인). 고르기 전에는 승인 버튼이 눌리지 않아요.
  5. "승인"(Approve)을 탭해요. 모르는 기기면 "거절"(Deny)을 탭하세요.
  6. 새 기기에 "새기기등록이 완료되었습니다"가 뜨고, 사장님이 골라준 용도의 화면으로 저절로 들어가요.
용도는 새 기기가 아니라 사장님이 정해요. 새 기기는 "나는 직원 주문용이에요"라고 스스로 말할 수 없어요. 메인 계산대 앞에 서 있는 사람만 용도를 고를 수 있으니, 누가 몰래 태블릿을 붙여도 마음대로 쓰지 못해요.
메인 계산대는 이 방법으로 만들 수 없어요. 메인 계산대는 언제나 이메일로 로그인해서 정해요. 바꿀 때는 확인 코드가 사장님 이메일로 가요. 추가 계산대(Sub POS)도 마찬가지로 이메일 로그인으로 등록하고 확인 코드를 받아요.
"메인포스를 찾지 못했습니다"라고 나오면? 대개 두 기기가 서로 다른 Wi-Fi에 있어서예요. 손님용 Wi-Fi나 휴대폰 핫스팟이 아니라 매장 Wi-Fi에 연결하고 "다시 시도"(Try again)를 탭하세요. 승인 팝업을 너무 오래 두면 "요청이 만료되었습니다"가 뜨는데, 새 기기에서 다시 시도하면 돼요.

메인 계산대의 Settings › Devices(기기)에는 이제 등록 버튼 대신 "How to add a device"(기기 추가 방법) 안내가 있어요 — 등록은 언제나 새 기기 쪽에서 시작해요.

기기 용도 바꾸기 & 연결 확인

이미 붙여 놓은 기기의 용도를 바꾸거나, 지금 메인 계산대와 잘 붙어 있는지 확인할 수 있어요.

  1. 직원 주문(Staff Ordering) 기기 화면 맨 위의 기기 모드 아이콘(Switch device mode)을 탭해요.
  2. "기기 용도 변경"(Change device role) 창이 열려요. 코드를 다시 넣을 필요는 없어요 — 이미 등록된 기기라서요.
  3. 새 용도를 골라요 — Staff Ordering(어떤 기기에서든 주문 받기) · Customer Display(손님에게 주문 보여주기) · Waitlist Kiosk(대기열 셀프 체크인).
  4. 아직 태블릿은 아무것도 바뀌지 않아요. "메인POS 승인 대기 중"(Waiting for Main POS approval)이라고 뜨고 "메인POS 화면에서 사장님이 승인해 주셔야 합니다. 이 기기는 아직 아무것도 바뀌지 않았습니다."라고 알려줘요.
  5. 메인 계산대로 가세요. 카드가 저절로 떠요 — "역할 변경 — 기존 기기"(Role change — existing device) 표시와 함께 "이미 등록된 기기가 역할 변경을 요청했습니다. 승인하면 이 기기가 하는 일이 바뀝니다(로그인은 그대로입니다)."라고 나와요. "승인"(Approve)을 누르면 태블릿이 바뀌고, 예상 못 한 요청이면 "거절"(Deny)을 누르세요.
  6. 창 맨 위에 연결 상태가 보여요 — "Connected to the main POS"(메인 계산대에 연결됨)면 정상이에요. "No main POS connected"면 아직 못 찾은 거예요. "Check again"(다시 확인)을 탭해 보세요.
  7. 이 기기를 완전히 떼려면 맨 아래 "Log out & unregister"(로그아웃 & 등록 해제)를 탭해요. 로그인 화면으로 돌아가고, 다시 로그인하면 처음부터 용도를 고를 수 있어요.
연결이 이상할 때 — "Connection log"(연결 기록). 화면 맨 위의 연결 기록 아이콘을 탭하면 이 기기가 지금 어느 매장에 어떤 용도로 붙어 있는지, 메인 계산대와 얼마나 오래 이어져 있었는지, 아직 못 보낸 주문이 몇 건인지 한 화면에서 볼 수 있어요. 지원팀에 문의할 때 "Copy all"(전체 복사)로 그대로 붙여 보내면 가장 빨라요.
이제 용도를 바꾸려면 사장님 승인이 필요해요. 태블릿을 손에 든 사람은 요청만 할 수 있고, 실제로 바꾸는 건 메인 계산대예요 — 손님이나 지나가는 사람이 몰래 키오스크를 주문 기기로 바꿔놓을 수 없어요. 요청은 2분 뒤 만료돼요("이 요청은 {seconds}초 뒤 만료됩니다 — 지금 승인하거나, 기기에서 다시 요청하세요"). 시간이 지났으면 태블릿에서 다시 요청하면 돼요.
서브 POS로 바꿀 때는 두 번 물어봐요. 서브 POS는 돈을 받을 수 있으니 메인 계산대가 먼저 경고해요 — "이 기기는 결제를 받을 수 있게 됩니다."(This device will be able to take payments.) / "서브 POS는 주문·결제·환불을 할 수 있습니다. 직접 설치한 기기만 승인하세요." 확인하려면 "계속"(Continue)을 누르세요. 모르는 기기라면 "거절"(Deny)을 누르세요.

기기 수를 다 썼을 때 — 한 대 바꿔 끼우기

플랜마다 쓸 수 있는 계산대·고객 디스플레이 대수가 정해져 있어요. 그 수에 닿으면 BrewDesk가 그냥 막기만 하지 않고 맞교체를 제안해요.

보이는 곳

설정(Settings) › 기기(Devices) 맨 위에 경고 띠가 떠요. 넘겼을 때가 아니라 한도에 닿는 순간부터 떠요 — POS 3/3, Customer display 1/1처럼 몇 대를 쓰는지 같이 보여줘요. 기기마다 "마지막 접속"(Last seen)도 보여서, 서랍에 들어가 있는 기기가 어느 것인지 알 수 있어요.

  1. 새 계산대를 평소처럼 등록해요. 한도에 걸리면 이렇게 떠요 — "이 플랜의 기기 한도에 도달했습니다. 기존 기기를 교체하거나 플랜을 업그레이드하세요."
  2. "기기 교체"(Replace a device) 창이 열리고, 뺄 수 있는 기기 목록이 나와요. 하나 고르세요.
  3. 끝이에요. 고른 기기가 연결 해제되고 새 기기가 그 자리를 바로 이어받아요.
  4. 목록이 오래됐다면? 고른 기기가 이미 빠진 상태면 "그 기기는 이미 연결 해제되었거나 목록이 오래된 것 같아요 — 목록을 다시 불러올게요."라고 해요. 새로 뜬 목록에서 다시 고르면 돼요.
메인 계산대는 그 목록에 절대 안 나와요. 메인 POS 교체는 더 큰 일이라 길이 따로 있어요 — "Replace Main POS"(메인 POS 교체) 카드로 들어가서 확인을 거치고 이메일 인증 코드까지 받아야 해요. 위의 빠른 맞교체는 추가 기기 전용이에요.
사장님께도 메일이 가요. 웹에서 한도 때문에 기기 등록이 막히면 매장 사장님께 안내 메일도 함께 보내요 — 화면에 "매장 사장님께도 이메일로 알려드렸어요."라고 나와요. 아침 7시에 직원이 이 화면을 만나도, 사장님이 나중에 전해 듣지 않고 바로 알 수 있어요.
Staff Ordering은 대수를 따로 세요. 스태프 오더링 슬롯이 다 찼으면 등록 화면에 글로 알려줘요 — "스태프 오더링 슬롯 2개가 모두 사용 중입니다 (2/2). 설정 → 기기에서 기기를 해제하면 한 대 더 넣을 수 있어요." 플랜에 아예 없으면 "현재 플랜에는 스태프 오더링이 포함되어 있지 않습니다."라고 나와요.

아이패드·데스크탑 앱에서는 문구가 조금 짧고, 플랜 변경은 웹의 BrewDesk 계정에서 하라고 안내해요 — 교체하는 방법 자체는 똑같아요.
