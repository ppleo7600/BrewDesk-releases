14여러 대 기기 & 안정성

여러 대의 기기를 동시에 사용할 수 있습니다. 하나가 고장 나도 다른 기기가 가게를 계속 운영해 줍니다. 기기를 설정해 보겠습니다.

  1. 각 기기에서 BrewDesk를 열고 로그인합니다.
  2. 각 기기에 역할을 지정합니다. 메인 계산대(1번 기기), 추가 계산대(도우미 기기), 디스플레이(손님용 화면) 중에서 선택합니다.
  3. 나중에 기기 역할을 바꿔야 하면 대시보드에서, 멀리서도 변경할 수 있습니다.
  4. 한 기기를 메인 계산대로 지정합니다 — 이것이 기준(앵커)입니다. 자동으로 넘어가지 않습니다. 메인 계산대가 오프라인이 되면 BrewDesk가 바로 알려 주므로, 다시 켜거나 다른 기기를 메인 계산대로 지정할 수 있습니다.
  5. Staff Ordering을 포함해 기기 모드를 설정하려면 13장을 참고해 주세요.
메인 계산대가 오프라인이 되면. 바로 알려 드립니다 — 인박스 알림, 이메일, 그리고 다른 계산대의 배너로 안내합니다. 다른 계산대는 계속 작동하지만, QR·온라인 주문은 메인 계산대가 돌아올 때까지 잠시 중단됩니다(11장 참고). 다른 기기를 메인 계산대로 바꾸려면 사장님이 직접 전환해야 하며, BrewDesk가 확인용 코드를 이메일로 보냅니다 — 아무것도 자동으로 조용히 넘어가지 않습니다.
기기마다 이름을 붙여 보시기 바랍니다. Settings › Devices에서 기기 이름(또는 옆의 작은 연필 아이콘)을 누르고, "카운터 1", "바 아이패드"처럼 입력한 뒤 저장합니다. "Device name updated."가 표시됩니다. 이름은 모든 기기에 동일하게 표시되므로 어떤 태블릿이 어떤 기기인지 항상 알 수 있습니다. 매장 네트워크로만 연결된 기기는 이름을 변경할 수 없습니다. (일부 문구는 영어로 표시됩니다.)
메인 계산대를 목록에서 제거하려는 경우. QR·온라인 주문이 켜져 있으면 먼저 경고가 표시됩니다: 메인 POS 입니다. QR·온라인 주문이 켜져 있어, 메인 POS 가 없는 동안에는 손님 주문을 받을 수 없고 주방 인쇄도 되지 않습니다… 경고만 하고 막지는 않으므로 계속 진행할 수 있습니다. 가능하면 다른 기기를 먼저 메인 계산대로 지정해 두어 주세요.
이 점을 자랑해 보시기 바랍니다

계산대는 절대 멈추지 않습니다. 음료를 쏟았나요? 아무 노트북이나 태블릿을 사용하면 몇 분 안에 복구됩니다. 특별한 기계도 필요 없고, 특정 기기에 묶이는 일도 없습니다.

새 기기를 메인 계산대에 붙이기

직원 주문용 태블릿, 고객 디스플레이, 체크인 화면을 새로 연결할 때는 메인 계산대가 자동으로 찾아 줍니다. 코드를 입력할 필요도, 설정을 뒤질 필요도 없습니다. 인터넷이 끊긴 매장에서도 가능합니다.

준비물

새 기기에 BrewDesk 앱이 설치되어 있어야 합니다(아이패드 · 안드로이드 태블릿 · 데스크탑). 그리고 메인 계산대와 같은 매장 Wi-Fi에 연결되어 있어야 합니다. 인터넷 브라우저로 연 화면은 기기로 등록할 수 없습니다 — 그 경우 "Add devices from the BrewDesk app"(BrewDesk 앱에서 기기를 추가해 주세요)라고 안내합니다.

  1. 새 기기에서 BrewDesk 앱을 엽니다. 로그인 화면 아래의 "메인포스에 새기기로 등록"(Register as a new device at Main POS)을 탭합니다. 인터넷이 끊긴 상태라면 이 화면으로 자동으로 넘어갑니다.
  2. "메인포스 찾는 중…"(Looking for Main POS...)이 표시되고, 찾으면 요청을 자동으로 보냅니다. 새 기기에서는 더 누를 것이 없습니다 — "메인포스에서 승인을 기다리는 중입니다"(Waiting for approval at the Main POS)가 표시되면 그대로 두어 주세요.
  3. 메인 계산대 화면에 "새 기기 페어링 요청"(New device pairing request) 팝업이 자동으로 나타납니다. 어떤 기기가 요청했는지 이름과 주소가 표시됩니다.
  4. 팝업의 "기기 용도"(Device role)에서 이 기기를 무엇으로 사용할지 선택합니다 — Staff Ordering(직원 주문) · Customer Display(고객 디스플레이) · Waitlist Kiosk(대기열 셀프 체크인). 선택하기 전에는 승인 버튼이 눌리지 않습니다.
  5. "승인"(Approve)을 탭합니다. 모르는 기기라면 "거절"(Deny)을 탭해 주세요.
  6. 새 기기에 "새기기등록이 완료되었습니다"가 표시되고, 사장님이 선택한 용도의 화면으로 자동으로 들어갑니다.
용도는 새 기기가 아니라 사장님이 정합니다. 새 기기는 "나는 직원 주문용입니다"라고 스스로 지정할 수 없습니다. 메인 계산대 앞에 있는 사람만 용도를 선택할 수 있으므로, 누군가 몰래 태블릿을 연결해도 마음대로 사용할 수 없습니다.
메인 계산대는 이 방법으로 만들 수 없습니다. 메인 계산대는 언제나 이메일로 로그인해서 지정합니다. 변경할 때는 확인 코드가 사장님 이메일로 전송됩니다. 추가 계산대(Sub POS)도 마찬가지로 이메일 로그인으로 등록하고 확인 코드를 받습니다.
"메인포스를 찾지 못했습니다"라고 표시되면? 대개 두 기기가 서로 다른 Wi-Fi에 있기 때문입니다. 손님용 Wi-Fi나 휴대폰 핫스팟이 아니라 매장 Wi-Fi에 연결하고 "다시 시도"(Try again)를 탭해 주세요. 승인 팝업을 너무 오래 두면 "요청이 만료되었습니다"가 표시되는데, 이 경우 새 기기에서 다시 시도하면 됩니다.

메인 계산대의 Settings › Devices(기기)에는 이제 등록 버튼 대신 "How to add a device"(기기 추가 방법) 안내가 있습니다 — 등록은 언제나 새 기기 쪽에서 시작합니다.

기기 용도 바꾸기 & 연결 확인

이미 연결해 둔 기기의 용도를 바꾸거나, 현재 메인 계산대와 정상적으로 연결되어 있는지 확인할 수 있습니다.

  1. 직원 주문(Staff Ordering) 기기 화면 맨 위의 기기 모드 아이콘(Switch device mode)을 탭합니다.
  2. "기기 용도 변경"(Change device role) 창이 열립니다. 코드를 다시 입력할 필요는 없습니다 — 이미 등록된 기기이기 때문입니다.
  3. 새 용도를 선택합니다 — Staff Ordering(어떤 기기에서든 주문 받기) · Customer Display(손님에게 주문 보여 주기) · Waitlist Kiosk(대기열 셀프 체크인).
  4. 아직 태블릿에는 아무것도 바뀌지 않습니다. "메인POS 승인 대기 중"(Waiting for Main POS approval)이라고 표시되며 "메인POS 화면에서 사장님이 승인해 주셔야 합니다. 이 기기는 아직 아무것도 바뀌지 않았습니다."라고 안내합니다.
  5. 메인 계산대로 이동해 주세요. 카드가 자동으로 나타납니다 — "역할 변경 — 기존 기기"(Role change — existing device) 표시와 함께 "이미 등록된 기기가 역할 변경을 요청했습니다. 승인하면 이 기기가 하는 일이 바뀝니다(로그인은 그대로입니다)."라고 표시됩니다. "승인"(Approve)을 누르면 태블릿이 바뀌며, 예상하지 못한 요청이라면 "거절"(Deny)을 눌러 주세요.
  6. 창 맨 위에 연결 상태가 표시됩니다 — "Connected to the main POS"(메인 계산대에 연결됨)이면 정상입니다. "No main POS connected"이면 아직 찾지 못한 상태입니다. "Check again"(다시 확인)을 탭해 주세요.
  7. 이 기기를 완전히 해제하려면 맨 아래 "Log out & unregister"(로그아웃 & 등록 해제)를 탭합니다. 로그인 화면으로 돌아가며, 다시 로그인하면 처음부터 용도를 선택할 수 있습니다.
연결이 이상할 때 — "Connection log"(연결 기록). 화면 맨 위의 연결 기록 아이콘을 탭하면 이 기기가 현재 어느 매장에 어떤 용도로 연결되어 있는지, 메인 계산대와 얼마나 오래 연결되어 있었는지, 아직 전송하지 못한 주문이 몇 건인지 한 화면에서 확인할 수 있습니다. 지원팀에 문의할 때 "Copy all"(전체 복사)로 그대로 붙여 보내면 가장 빠릅니다.
이제 용도를 바꾸려면 사장님 승인이 필요합니다. 태블릿을 손에 든 사람은 요청만 할 수 있고, 실제로 변경하는 것은 메인 계산대입니다 — 손님이나 지나가는 사람이 몰래 키오스크를 주문 기기로 바꿀 수 없습니다. 요청은 2분 뒤 만료됩니다("이 요청은 {seconds}초 뒤 만료됩니다 — 지금 승인하거나, 기기에서 다시 요청해 주세요"). 시간이 지났다면 태블릿에서 다시 요청하면 됩니다.
서브 POS로 바꿀 때는 두 번 확인합니다. 서브 POS는 결제를 받을 수 있으므로 메인 계산대가 먼저 경고합니다 — "이 기기는 결제를 받을 수 있게 됩니다."(This device will be able to take payments.) / "서브 POS는 주문·결제·환불을 할 수 있습니다. 직접 설치한 기기만 승인해 주세요." 확인하려면 "계속"(Continue)을 눌러 주세요. 모르는 기기라면 "거절"(Deny)을 눌러 주세요.

기기 수를 다 썼을 때 — 한 대 바꿔 끼우기

플랜마다 사용할 수 있는 계산대·고객 디스플레이 대수가 정해져 있습니다. 그 수에 도달하면 BrewDesk는 단순히 막기만 하지 않고 맞교체를 제안합니다.

표시되는 곳

설정(Settings) › 기기(Devices) 맨 위에 경고 띠가 표시됩니다. 초과했을 때가 아니라 한도에 도달하는 순간부터 표시됩니다 — POS 3/3, Customer display 1/1처럼 몇 대를 사용 중인지 함께 보여 줍니다. 기기마다 "마지막 접속"(Last seen)도 표시되므로, 서랍에 들어가 있는 기기가 어느 것인지 알 수 있습니다.

  1. 새 계산대를 평소처럼 등록합니다. 한도에 걸리면 다음과 같이 표시됩니다 — "이 플랜의 기기 한도에 도달했습니다. 기존 기기를 교체하거나 플랜을 업그레이드해 주세요."
  2. "기기 교체"(Replace a device) 창이 열리고, 제거할 수 있는 기기 목록이 표시됩니다. 하나를 선택해 주세요.
  3. 이것으로 끝입니다. 선택한 기기가 연결 해제되고 새 기기가 그 자리를 바로 이어받습니다.
  4. 목록이 오래되었다면? 선택한 기기가 이미 제거된 상태라면 "그 기기는 이미 연결 해제되었거나 목록이 오래된 것 같아요 — 목록을 다시 불러올게요."라고 안내합니다. 새로 표시된 목록에서 다시 선택하면 됩니다.
메인 계산대는 그 목록에 절대 나타나지 않습니다. 메인 POS 교체는 더 중대한 작업이라 별도의 절차가 있습니다 — "Replace Main POS"(메인 POS 교체) 카드로 들어가 확인을 거치고 이메일 인증 코드까지 받아야 합니다. 위의 빠른 맞교체는 추가 기기 전용입니다.
사장님께도 메일이 발송됩니다. 웹에서 한도 때문에 기기 등록이 막히면 매장 사장님께 안내 메일도 함께 보냅니다 — 화면에 "매장 사장님께도 이메일로 알려드렸어요."라고 표시됩니다. 아침 7시에 직원이 이 화면을 만나더라도, 사장님이 나중에 전해 듣지 않고 바로 알 수 있습니다.
Staff Ordering은 대수를 따로 셉니다. 스태프 오더링 슬롯이 모두 찼으면 등록 화면에 문구로 안내합니다 — "스태프 오더링 슬롯 2개가 모두 사용 중입니다 (2/2). 설정 → 기기에서 기기를 해제하면 한 대 더 넣을 수 있어요." 플랜에 아예 없으면 "현재 플랜에는 스태프 오더링이 포함되어 있지 않습니다."라고 표시됩니다.

아이패드·데스크탑 앱에서는 문구가 조금 더 짧고, 플랜 변경은 웹의 BrewDesk 계정에서 하도록 안내합니다 — 교체하는 방법 자체는 동일합니다.
