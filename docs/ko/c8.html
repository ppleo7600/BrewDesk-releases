8할인 & 프로모션

할인은 판매 금액에서 돈을 빼는 거예요. 해피 아워와 행사를 한 번만 설정하면 BrewDesk가 계산대에서 계산을 대신해줘요.

  1. Discounts를 열고 "Add Discount"를 탭해요. "Create Discount" 양식이 열려요.
  2. Discount Name(할인 이름)을 입력해요.
  3. Discount Type을 골라요 — "Percentage"(10% 할인 같은) 또는 "Fixed Amount"($2 할인 같은) — 그리고 Value(값)를 입력해요.
  4. Schedule(일정)을 정해요: 시작·종료 날짜, "All Day"나 시간대, 끝나지 않으면 "No End Date", 반복(반복 없음 / 매주 / 매월 / 사용자 지정).
  5. Applicable Scope(적용 범위)에서 어디에 적용할지 골라요: "All"(모든) 상품, 또는 체크박스로 특정 카테고리나 상품을 선택.
  6. 어떻게 적용될지 골라요: Automatic(결제 때 저절로 빠짐) 또는 Manual(직원이 결제 때 "Apply Discount"를 탭해 골라요).
  7. 선택: Minimum Order Value(최소 주문 금액)를 정하고, 다른 할인과 합쳐지게 하려면 "Allow Stacking"을 켜요.
  8. "Save"를 탭해요. 할인이 준비됐어요.
알아두면 좋아요: BrewDesk는 항상 할인 후에 세금을 계산해서 합계가 늘 정확해요.

계산대에서 바로 깎기 · 서비스로 주기

미리 만들어 두는 할인은 매주 반복되는 일에 쓰는 거예요. 이건 그때 한 번뿐인 일에 쓰는 거예요 — 단골에게 조금 깎아드리거나, 다시 만들어 드린 음료거나, 지인에게 커피 한 잔이거나. 장바구니에서 세 번 정도 탭하면 끝나요.

여는 곳

장바구니에서 상품을 탭하면 그 줄에 "Discount"(할인) · "Free"(서비스) 버튼이 있어요. 주문 전체에 적용하려면 아래쪽 Bill 옆의 "Disc" 버튼을 탭해요.

  1. 상품 하나면 "Discount", 주문 전체면 "Disc"를 탭해요. 숫자판 패널이 열려요.
  2. 어떻게 넣을지 골라요 — 금액(Amount)이나 % 퍼센트(Percent).
  3. 숫자판으로 값을 입력해요.
  4. 사유 칩을 하나 탭해요 — 지인(Friend) · 사과(Apology) · 직원(Staff) · 시식(Tasting) · 실수(Mistake). 없으면 "+ 추가"(+ New)로 직접 적어요. 직접 적은 사유는 다음에 다시 나와요.
  5. "완료"(Done)를 탭하면 장바구니 합계가 바로 바뀌어요.
  6. 되돌리려면 같은 버튼을 다시 탭해요 — 그때는 "할인 해제"(Remove Discount) 또는 "서비스 해제"(Remove Free)라고 떠요.
전액을 입력했나요? BrewDesk가 "전액입니다. 서비스로 기록할까요?"라고 물어보고 "서비스로 기록" 버튼을 줘요. 그렇게 해 두면 리포트에서 "그냥 드린 것"과 "깎아 드린 것"이 갈려요 — 월말에 사장님이 정말 알고 싶은 건 그 구분이거든요.
설정에서 만든 할인을 "Manual"로 해 두셨나요? 주문 전체를 조정할 때 이 패널 안에 타일로 나와서, 직원은 숫자를 칠 필요 없이 탭만 하면 돼요. 아직 만든 게 없으면 "Create discount" 버튼이 나와서 만드는 화면으로 데려다줘요.
할인한 뒤에 수량을 바꿨다면? 조정이 취소되고 "수량이 바뀌어 조정이 취소되었습니다"라고 떠요. 일부러 그렇게 했어요 — 두 잔에서 2,000원 깎은 것과 다섯 잔에서 2,000원 깎은 건 다른 이야기라, 짐작해서 넘기느니 한 번 더 여쭤보는 쪽을 골랐어요.

서비스로 나간 상품은 마감 요약에 따로 한 줄로 나와요 — 17장을 보세요.
