5주문 받기

가장 중요한 일은 주문을 받는 것입니다. 카운터 가게와 테이블 가게는 작동 방식이 조금 다릅니다. 아래에서 본인에게 맞는 방법을 확인해 주세요.

  1. 카운터에서 받는 경우: 손님이 원하는 상품을 하나씩 탭합니다. 화면 옆 주문에 담깁니다.
  2. 같은 상품을 다시 탭하면 수량이 늘어납니다. 숫자가 올라갑니다.
  3. 주문이 끝나면 Pay Now를 탭해 결제를 받습니다.
  4. 테이블에서 받는 경우: 테이블 맵(매장 배치도 그림)을 엽니다. 손님이 앉은 테이블을 탭합니다. 그러면 해당 주문이 시작됩니다.
  5. 같은 방식으로 상품을 추가합니다 — 하나씩 탭해 주세요.
  6. 주방에 특별 메모가 필요하다면 상품을 탭하고 상품 메모를 추가합니다. "아주 뜨겁게"나 "얼음 빼고" 같은 내용입니다.
  7. 잠시 멈추고 나중에 다시 와야 한다면 "Hold"를 탭합니다. 주문이 저장됩니다. 언제든 다시 열 수 있습니다 (아래 "주문 보류" 참고).
포장 주문은 어떻게 되나요? 포장 주문(가지고 나가는 음식)은 테이블 주문과 따로 보관되므로 절대 섞이지 않습니다.

주문 보류(Hold)

주문을 나중을 위해 세워 두는 기능입니다. 때로는 주문을 바로 끝낼 수 없는 경우가 있습니다 — 손님이 자리를 비우거나, 새 손님이 다가오는 경우입니다. "Hold"는 주문을 세워 두고 나중에 다시 이어 갈 수 있게 합니다. 결제되는 것도 없고, 잃어버리는 것도 없습니다.

  1. 주문 패널 아래쪽을 확인합니다. "Disc"(할인) 바로 옆에 "Hold" 버튼이 있습니다.
  2. "Hold"를 탭합니다. 누구에게도 결제를 청구하지 않고 주문이 보류됩니다. 화면이 비워지므로 다음 손님을 받을 수 있습니다.
  3. 테이블에서는 보류한 주문이 해당 테이블에 그대로 붙어 있어 다시 찾기 쉽습니다.
  4. 다시 가져오려면 보류 주문 목록을 열고 주문을 탭해 다시 엽니다.
  5. 주문이 그대로 돌아옵니다. 상품을 더 담아도 되고, 이어서 Pay Now로 진행해도 됩니다.
언제 Hold를 사용하나요? 손님이 무언가를 가지러 자리를 비웠을 때, 또는 다른 사람의 주문을 먼저 받아야 할 때 사용해 주세요. 보류한 주문은 준비될 때까지 안전하게 보관됩니다 — 아무것도 잃지 않습니다.

테이블 맵 만들기

테이블에서 주문을 받는다면, 테이블 맵은 매장을 작게 그린 그림입니다. 테이블을 탭하면 해당 테이블의 주문이 시작됩니다. 한 번만 설정하면 됩니다. 그리는 방법은 다음과 같습니다.

켜는 곳

식당과 바 업종은 테이블 서비스가 기본으로 켜져 있습니다. 그렇지 않으면 Settings › Add-ons › Tables에서 켭니다(스위치를 눌러 주세요). 테이블 맵은 테이블 서비스가 켜져 있을 때만 표시됩니다.

시작 전에: 테이블 서비스가 켜져 있는지 확인해 주세요 (위 박스 참고).

  1. Table Map을 엽니다 — 왼쪽 사이드바의 Tables(테이블)를 탭합니다. (테이블 서비스가 켜져 있을 때만 표시됩니다.)
  2. 화면 위쪽 Table Map 탭 옆의 톱니 아이콘(Edit Layout, 레이아웃 편집)을 탭해 편집 화면으로 들어갑니다. 테이블이 하나도 없다면 화면 가운데의 Open Editor(편집기 열기) 버튼을 탭해도 됩니다. 여기서 매장을 구성합니다.
  3. 위쪽 도구 막대에서 추가할 모양의 버튼을 탭합니다 — Round(원형)·Square(정사각형)·Rect(직사각형)·Wall(벽), 그리고 Counter(카운터)·Door(출입문)·WC(화장실). 새 테이블(또는 구조물)이 나타납니다.
  4. 추가한 테이블을 탭하면 오른쪽에 편집 패널이 열립니다. 이름(Name)("T1"이나 "Patio 3" 같은), 좌석 수(Seats), 모양(Shape), 크기(Size), 색(Color)을 정하고 Done을 탭합니다. 선택하는 대로 테이블 모양이 바뀌는 것을 확인할 수 있습니다.
  5. 실제 매장에 있는 위치로 테이블을 끌어다 놓습니다.
  6. 가진 테이블마다 반복합니다.
  7. 완료되면 왼쪽 위의 Table Map(뒤로 가기) 버튼으로 맵 화면으로 돌아갑니다. 이제 테이블을 탭해 매장 식사 주문을 시작할 수 있습니다.
너무 신경 쓰지 않으셔도 됩니다. 맵이 완벽할 필요는 없습니다. 테이블을 구분할 수만 있으면 충분합니다. 테이블은 언제든 옮길 수 있습니다.

테이블 이동 & 합치기

드래그 & 드롭으로 옮기고 합칩니다. 손님의 마음은 바뀔 수 있습니다. 누군가는 테라스로 옮기고 싶어 하고, 두 테이블이 함께 계산하기도 합니다. 테이블 맵에서는 테이블의 주문 전체를 집어서 다른 곳에 놓을 수 있습니다 — 다시 입력할 필요가 없습니다.

어디서 찾나요

테이블 맵에 기본으로 들어 있습니다. 테이블(Table service)이 켜져 있으면 언제든 사용할 수 있으며, 따로 켤 필요가 없습니다.

주문을 빈 테이블로 옮기기 (이동)

  1. 사용 중인 테이블을 잠깐 길게 누르면 테이블이 살짝 떠오릅니다. 그 상태로 빈 테이블 위로 끌어다 놓습니다.
  2. 작은 창이 "Move T1 to T3?"라고 묻습니다 — Move를 탭하면 주문 전체가 새 테이블로 넘어가고, 원래 테이블은 비워집니다. 테이블 이름은 그대로입니다.

사용 중인 두 테이블을 한 계산서로 합치기 (합치기)

  1. 사용 중인 테이블을 길게 누른 채, 다른 사용 중인 테이블 위로 끌어다 놓습니다.
  2. 이번에는 창 제목이 "Move T1 onto T2?"로 바뀌고, Move는 회색("Move unavailable")으로 막힌 채 Merge 카드가 표시됩니다 — "T1 + T2 into one order on T2." 탭하면 두 주문이 놓은 테이블 하나의 계산서로 합쳐지고, 다른 테이블은 비워집니다.
엉뚱한 테이블에 놓았다면 이동·합치기 직후 약 6초 동안 "Undo" 버튼이 표시됩니다 — 탭하면 원래대로 되돌아갑니다. (단, 합친 계산서에 새 상품을 담거나 결제를 받은 뒤에는 합치기를 되돌릴 수 없습니다.)
자랑할 만한 점

일행 전체를 손가락 하나로 옮깁니다. 다른 계산대는 테이블만 바꾸려 해도 주문을 취소하고 처음부터 다시 입력하게 합니다. BrewDesk는 밀어서 옮기기만 하면 되고, 6초 되돌리기가 있어 손이 미끄러져도 매출을 잃지 않습니다.

알아두기: 예약된 테이블에 놓으면 먼저 경고가 표시됩니다. 합친 계산서는 주 테이블의 할인을 그대로 사용하며, 모든 테이블은 여전히 깔끔한 하나의 주문으로 유지됩니다.

주문이 없는데 테이블이 사용 중으로 표시된다면 가끔 테이블이 열렸지만(예: QR 스캔) 주문이 들어가지 않아 사용 중 표시가 남는 경우가 있습니다. 지도에서 해당 테이블을 탭하면 BrewDesk가 정리(clear, 빈 테이블로 되돌리기)하거나 새 주문 열기(open)를 제안합니다. 정리는 주문도 결제도 없는 테이블에서만 가능하므로 실제 매출을 잃을 일이 없습니다.
